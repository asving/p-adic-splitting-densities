**The one structural observation that shapes the whole unit.** `InductionPackage 3`
(H.95) is EXISTENTIAL in the rate constants `(K, B, c)` — they must be uniform over every
complete DVR `O` with finite residue field, but they need not be H.97's hypothesized
`(1, 1, 0)`. So the unit's target is a rate theorem with ANY uniform constants, fed
directly into `InductionPackage 3`; H.97's landed statement is untouched.

**The crux, verified (not assumed).** `RateSpecies Q K B c f` (H.65) demands
`f M ≤ K·M^B·(Q^(M−c))⁻¹` — exponential decay at rate `q^(−M)` exactly, up to a
polynomial factor and a constant shift. The landed drainage chain (leancheck sidecar
`N3Drain3` @ `b00b0505`) proves only

* peel branch: `undecidedSeq O 3 (2M) ≤ q^(−M) + tripleUndecidedSeq (2M)` — a
  `q^(−N/2)` rate, via `class_pinned`-style tangency counting at even levels;
* triple branch: `tripleUndecidedSeq (M+3) ≤ q^(−2)·undecidedSeq O 3 M` — the lossy
  uniform-precision constant.

Unrolled, that chain gives `s(N) = O(q^(−N/2))` — **not** RateSpecies-shaped for any
`(K, B, c)`. Both branches must be sharpened to rate 1:

* **peel branch sharp**: route through chapter G's EXACT `n = 2` law
  `undecidedCount O 2 N = q^N` (G.36) instead of tangency-pinning — gives `q^(−N)` at
  every level `N ≥ 1`;
* **triple branch sharp**: the mixed-precision `(M, M+1, M+2)` recording of the
  extraction (leancheck `N3MBox` @ `b00b0505`) — gives the `q^(−5)` constant of
  `N3_CHECK` §13.5, here applied to the UNDECIDED set (new statement; the landed
  `N3InertLower`/`N3InertExact` apply it to the decided/possible sets).

Then `s(M+3) ≤ q^(−(M+3)) + q^(−5)·s(M)`, and the unroll (S8) gives
**`(K, B, c) = (1, 0, 3)`**: `undecidedSeq O 3 M ≤ (q^(M−3))⁻¹` for every `M ≥ 1`,
every `O`. That is `RateSpecies (residueCard O) 1 0 3 (undecidedSeq O 3)`.

**Why H.97's literal `hrate` (constants `(1,1,0)`) is NOT discharged here.** `(1,1,0)`
demands `s(1) ≤ q^(−1)`, which is TRUE with equality (the level-1 undecided classes are
exactly the `q²` repeated-root residue classes) but needs the exact level-1 census
(squarefree residue ⟹ decided, all three squarefree genres). The peel+triple counting
alone gives only `s(1) ≤ q^(−1) + q^(−2)`. Since `package_three` does not need `(1,1,0)`,
the census is out of scope; `hrate (1,1,0)` is recorded below as the narrowed residue of
H.97's frontier (true, numerically certified, unproved).
