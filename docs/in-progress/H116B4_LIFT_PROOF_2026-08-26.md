## 2. The filtration estimates (all PROVED)

**2.1 Lemma FE (one-grade filtration estimate).** For every x ∈ Λ, δ ∈ 𝒞, i ≥ 1:

    Φ(x + π^i δ) ≡ Φ(x) + π^i T_x(δ)   (mod π^{2i+1}).

*Proof.* By (1.4), the error is Σ_{d≥2} M_d(x; π^i δ) and M_d(x; π^i δ) = π^{id}M_d(x; δ).
Every subset S with |S| = d ≥ 2 contains at least d−1 ≥ 1 child blocks (there is only one
cofactor block), and each child factor λ_p(δ_p) ∈ π^{k_p}O[X] ⊆ πO[X] by (A2). Hence
v(M_d(x;δ)) ≥ d−1 ≥ 1 and v(π^{id}M_d) ≥ id + 1 ≥ 2i + 1. ∎

Degenerate case |L| = 1, r = 0: there are no d ≥ 2 terms at all and Φ is globally affine;
every statement below is then trivially true with zero error.

**2.2 Lemma DS (derivative stability).** For x, x' ∈ 𝒞 with x ≡ x' (mod π^j 𝒞), j ≥ 0:
T_x(δ) ≡ T_{x'}(δ) (mod π^{j+1}) for every δ ∈ 𝒞. In particular, since any two points of
Λ are congruent mod π·𝒞, the family {T_x mod π² : x ∈ Λ} is a SINGLE map; a fortiori
T_x mod π is one fixed map T̄.

*Proof.* T_x(δ) − T_{x'}(δ) expands multilinearly into terms containing one factor
λ_β(δ_β), one factor λ_{β'}(x_{β'} − x'_{β'}) with β' ≠ β, and C-or-λ factors. Since
β ≠ β', at least one of the two distinguished blocks is a child block, contributing
column content ≥ 1 by (A2); the difference block contributes π^j from the congruence.
Total: v ≥ j + 1. ∎

**2.3 Lemma GRADE (the explicit one-grade linear part).** The fixed reduction
T̄ : 𝔽^{s+r} → 𝔽^m of (2.2) is, for every x ∈ Λ,

    T̄(u, v) = Σ_{c<r} v_c · X^{s+c}     (child digits u act by ZERO),

so with W := span_𝔽{X^s, X^{s+1}, …, X^{m−1}} (dimension r):

    image(T̄) = W,     ker(T̄) = 𝔽^s ⊕ 0,     #ker(T̄) = q^s.

*Proof.* Reduce (1.5) mod π. Child columns: λ_p(δ) ≡ 0 by (A3)/(A2). Cofactor column:
λ_Q(v)·∏_p(C_p + λ_p(x_p)) ≡ (Σ v_c X^c)·X^s by (A3) and λ_p(x_p) ∈ π𝔪[X]. Degrees
s + c ≤ s + r − 1 = m − 1 < m, so no truncation by the low-m window occurs and the images
X^{s+c} are distinct basis monomials: image W, kernel exactly the child-digit space. ∎

Battery confirmation (`runs/wave-b/out_DEC5R_battery.log:48/:65/:74`): |image| = q^r
(2, 1, 1) and K = q^s (4, 81, 16) in CELL-1/2/4, one linear part per level. Lemma GRADE
derives all six numbers and the level/node-independence in closed form.

## 3. II-a: the one-grade lifting theorem (PROVED — map row GR-9)

Fix a monic degree-m target lift F ∈ O[X] (only F mod π^N matters; F ranges over pinned
lifts of target classes). For 1 ≤ n ≤ N define the level-n fibre

    S_n(F) := { x ∈ Λ/π^n 𝒞 : Φ(x) ≡ F (mod π^n) },

well-defined by FE. Truncation maps S_{n+1}(F) → S_n(F).  Since
`Λ/π𝒞 = π𝒞/π𝒞` is a singleton, `S_1(F)` is the single all-zero class if
`F ≡ X^m (mod π)` and empty otherwise.  For a pinned target lift `F_c`, the latter
congruence follows directly from `mem_maximalIdeal_classSect`; it does **not** assert that
`S_N(F_c)` is inhabited.  That separate GR-11 packaging statement is proved as MLIFT-3 in
§4.5.  **[MLF2 2026-08-27]**

**3.1 Definition (obstruction class).** For x ∈ S_n(F), n < N, choose any lift
x̂ ∈ Λ of x and set

    ω_n(x) := [ (F − Φ(x̂))/π^n  mod π ]  ∈  V := 𝔽^m / W.

Well-defined: (F − Φ(x̂)) ≡ 0 (mod π^n) since x ∈ S_n(F); replacing x̂ by x̂ + π^n δ
changes the digit by T_x(δ) mod π = T̄(δ) ∈ W (FE for the error, GRADE for the image). ∎

**3.2 THEOREM II-a (one-grade 0/K dichotomy).** Let 1 ≤ n < N, x ∈ S_n(F). Then

    #{ x' ∈ S_{n+1}(F) : trunc x' = x } = K·[ω_n(x) = 0],   with  K = q^s = q^{Σ_p μ_p}.

Moreover the set of lifts, when nonempty, is the coset structure: choosing x̂ and writing
lifts as x̂ + π^n(u,v) with (u,v) ∈ 𝔽^{s+r}, the solution set is
{(u, v*) : u ∈ 𝔽^s} for the unique v* with Σ v*_c X^{s+c} = (F − Φ(x̂))/π^n mod π — an
affine translate of ker(T̄), NOT canonically a subgroup of anything, and NOT the
nonlinear-fibre delta set (the CELL-2 separator stands; no set identification is made).

*Proof.* Lifts of `x` from `Λ/π^n𝒞` to `Λ/π^{n+1}𝒞` are exactly the classes
`x̂ + π^n(u,v)`, `(u,v) ∈ 𝔽^{s+r}`
(distinct digits give distinct classes). By FE (i = n, error ≥ 2n+1 ≥ n+1):
Φ(x̂ + π^n(u,v)) ≡ Φ(x̂) + π^n T̄(u,v) (mod π^{n+1}). The lift lies in S_{n+1}(F) iff
T̄(u,v) = (F − Φ(x̂))/π^n mod π. By GRADE this is solvable iff the right side lies in W,
i.e. iff ω_n(x) = 0, and then the solutions are v = v* unique, u free: exactly q^s. ∎

## 4. II-b: the pushforward invariant and what it buys (reductions PROVED)

**4.1 Definition (the invariant).** For 1 ≤ n < N and a monic target lift F with
S_n(F) ≠ ∅, let ω_n be as in 3.1 and

    U(n | F)  :≡  the fibres of ω_n : S_n(F) → V all have one cardinality
                  (ω_n is uniform on its image);
    I_n(F)    :=  #image(ω_n on S_n(F)).

U(n|F) and I_n(F) depend on F only through F mod π^n.

**4.2 THEOREM (aggregate law).** Fix F and n < N with S_n(F) ≠ ∅. For a lift
F' ≡ F (mod π^n), set ξ(F') := [(F' − F)/π^n mod π] mod W ∈ V; every element of V arises
this way, and F' is determined mod π^{n+1} by ξ(F') up to W-translates which have EQUAL
level-(n+1) counts. Then

    ω_n^{F'} = ω_n^{F} + ξ(F')      (global translation), hence
    #S_{n+1}(F') = K · #(ω_n^F)^{-1}(−ξ(F')).

Consequently: U(n|F) holds **iff** all reachable lifts F' of F receive the same count
#S_{n+1}(F') = K·#S_n(F)/I_n(F) — the battery's `(GR-10 mechanism)` check verbatim
(`out_DEC5R_battery.log:49/:66/:75`), including the support accounting: the number of
reachable next targets is q^r · I_n(F) (each ω-class is a W-coset of q^r target lifts).

*Proof.* The translation identity is immediate from Definition 3.1. Theorem 3.2 gives
#S_{n+1}(F') = K·#{x ∈ S_n(F) : ω_n^{F'}(x) = 0}. Uniform fibres ⟺ uniform nonzero
counts over the image, with the image swept exactly by the reachable ξ. ∎

**4.3 COROLLARY (count recursion).** If U(n|F) holds for all 1 ≤ n < N and S_N(F) ≠ ∅,
then

    #S_N(F) = q^{s(N−1)} / ∏_{n=1}^{N−1} I_n(F).                                   (4.1)

*Proof.* #S_{n+1}(F) = K·#S_n(F)/I_n(F) at each level (0 ∈ image since the tower is
nonempty up to N), #S_1 = 1, K = q^s. ∎
