## 1. Setting and the exact planted parametrization

residue field 𝔽 = O/𝔪 (finite of cardinality q wherever counting happens; the identities
of §§2–4 need no finiteness), and v = the π-adic valuation. Fixed data as in the signed

Write ŵ_p := resSect z_p (a fixed unit lift of z_p; unit because z_p ≠ 0).

**1.1 Closed form of the planted factor (CITED + re-derived, two independent legs).**
The landed definition is `alphaParent π b k ŵ = (alphaFrame b ŵ).scaleRoots (π^k)` with
`alphaFrame b ŵ = (monicPoly b).comp (X − C ŵ)`
(`leanfinal/Uniformity/ChapH/H115b.lean:88,100`), and coefficientwise

Derivation: monicPoly b = Y^μ + Σ_j b_j Y^j; comp(X − Cŵ) substitutes Y = X − ŵ;
scaleRoots(π^k) sends f(X) to π^{kμ} f(X/π^k) written coefficientwise
(coeff j ↦ coeff j · π^{k(μ−j)}), and π^{kμ}(X/π^k − ŵ)^j = π^{k(μ−j)}(X − ŵπ^k)^j.

Consequences used below, with names:

* **(A1) exact affineness.** P(b) = C_p + Σ_j b_j E_{p,j} with
  C_p := (X − ŵ_pπ^{k_p})^{μ_p} and E_{p,j} := π^{k_p(μ_p−j)}(X − ŵ_pπ^{k_p})^j.
  The columns E_{p,j} are constants of the frame (independent of b). Affineness is exact,
  not modulo anything.
* **(A2) column contents.** E_{p,j} ∈ π^{k_p(μ_p−j)}·O[X], and k_p(μ_p−j) ≥ k_p ≥ 1 for

* **(A3) residue reductions.** C_p ≡ X^{μ_p} (mod π) and E_{p,j} ≡ 0 (mod π), since
  ŵ_pπ^{k_p} ∈ 𝔪.

**1.2 The raw pair space.** A raw presentation is a pair x = (b, a): child coordinates
b = (b_{p,j})_{p∈L, j<μ_p} ∈ 𝔪^s and cofactor coordinates a = (a_c)_{c<r} ∈ 𝔪^r

`ChapH/H116b2.lean`). Write 𝒞 := O^{s+r} (the coordinate module) and Λ := 𝔪^{s+r} ⊂ 𝒞.
The cofactor polynomial is Q(a) := X^r + Σ_{c<r} a_c X^c. The multiplication map is

    Φ : Λ → O^m,   Φ(b,a) := (coefficients 0..m−1 of ∏_{p∈L} P_p(b_p) · Q(a)).      (1.2)

The product is monic of degree m (`plantedPoly_monic`, `plantedPoly_natDegree`), so its
class mod π^N is determined by Φ mod π^N. For a target class c of the genre, with
F := monicPoly(classSect c.1) its pinned monic lift, `proj_eq_iff_pow_dvd`
(`ChapH/H115c.lean:121`) converts the signed fibre condition
`proj (coeffs of plantedPoly) = c.1` into Φ(x) ≡ F (mod π^N) coefficientwise. Hence

    #Pres(c) = #{ x ∈ Λ/π^N Λ : Φ(x) ≡ F_c (mod π^N) },                            (1.3)

where x mod π^n is meaningful because Φ(x) mod π^n depends only on x mod π^n (special
case of (FE) below). NOTE: (1.3) counts the RAW pair fibre directly — the same object the
battery's tree block enumerates — so II-a/II-b as proved here feed the assembly either
directly at raw level or through the outline's Ghost×ImgPres factorization (rows GR-1..3);
both roads are recorded in §8.

**1.3 Block expansion.** Index the blocks by β ∈ L ∪ {Q}. Set λ_p(c) := Σ_{j<μ_p}
c_{p,j}E_{p,j} (O-linear, values in π^{k_p}O[X] by (A2)), λ_Q(c) := Σ_{c'<r} c_{c'} X^{c'}
(O-linear, content ≥ 0), C_Q := X^r. Since each block enters ∏(C_β + λ_β) exactly once,
Φ is affine-multilinear with the EXACT finite expansion, for any x ∈ Λ and any increment
vector δ ∈ 𝒞:

    Φ(x + δ) = Φ(x) + T_x(δ) + Σ_{d≥2} M_d(x; δ),                                   (1.4)
    T_x(δ)   = Σ_β λ_β(δ_β) · ∏_{β'≠β} (C_{β'} + λ_{β'}(x_{β'})),                   (1.5)
    M_d(x;δ) = Σ_{|S|=d} ∏_{β∈S} λ_β(δ_β) · ∏_{β∉S} (C_β + λ_β(x_β)),               (1.6)

all read through "low-m coefficients of". T_x is the multi-Sylvester differential at x on
the RAW coordinate module — the map whose restriction to the planted lattices is row 3's

## 2. The filtration estimates (all PROVED)

**2.1 Lemma FE (one-grade filtration estimate).** For every x ∈ Λ, δ ∈ 𝒞, i ≥ 1:

    Φ(x + π^i δ) ≡ Φ(x) + π^i T_x(δ)   (mod π^{2i+1}).

*Proof.* By (1.4), the error is Σ_{d≥2} M_d(x; π^i δ) and M_d(x; π^i δ) = π^{id}M_d(x; δ).
Every subset S with |S| = d ≥ 2 contains at least d−1 ≥ 1 child blocks (there is only one
cofactor block), and each child factor λ_p(δ_p) ∈ π^{k_p}O[X] ⊆ πO[X] by (A2). Hence
v(M_d(x;δ)) ≥ d−1 ≥ 1 and v(π^{id}M_d) ≥ id + 1 ≥ 2i + 1. ∎

Degenerate case |L| = 1, r = 0: there are no d ≥ 2 terms at all and Φ is globally affine;
every statement below is then trivially true with zero error.

**2.2 Lemma DS (derivative stability).** For x, x' ∈ 𝒞 with x ≡ x' (mod π^j 𝒞), j ≥ 0:
T_x(δ) ≡ T_{x'}(δ) (mod π^{j+1}) for every δ ∈ 𝒞. In particular, since any two points of
Λ are congruent mod π·𝒞, the family {T_x mod π² : x ∈ Λ} is a SINGLE map; a fortiori
T_x mod π is one fixed map T̄.

*Proof.* T_x(δ) − T_{x'}(δ) expands multilinearly into terms containing one factor
λ_β(δ_β), one factor λ_{β'}(x_{β'} − x'_{β'}) with β' ≠ β, and C-or-λ factors. Since
β ≠ β', at least one of the two distinguished blocks is a child block, contributing
column content ≥ 1 by (A2); the difference block contributes π^j from the congruence.
Total: v ≥ j + 1. ∎

**2.3 Lemma GRADE (the explicit one-grade linear part).** The fixed reduction
T̄ : 𝔽^{s+r} → 𝔽^m of (2.2) is, for every x ∈ Λ,

    T̄(u, v) = Σ_{c<r} v_c · X^{s+c}     (child digits u act by ZERO),

so with W := span_𝔽{X^s, X^{s+1}, …, X^{m−1}} (dimension r):

    image(T̄) = W,     ker(T̄) = 𝔽^s ⊕ 0,     #ker(T̄) = q^s.

*Proof.* Reduce (1.5) mod π. Child columns: λ_p(δ) ≡ 0 by (A3)/(A2). Cofactor column:
λ_Q(v)·∏_p(C_p + λ_p(x_p)) ≡ (Σ v_c X^c)·X^s by (A3) and λ_p(x_p) ∈ π𝔪[X]. Degrees
s + c ≤ s + r − 1 = m − 1 < m, so no truncation by the low-m window occurs and the images
X^{s+c} are distinct basis monomials: image W, kernel exactly the child-digit space. ∎

Battery confirmation (`runs/wave-b/out_DEC5R_battery.log:48/:65/:74`): |image| = q^r
(2, 1, 1) and K = q^s (4, 81, 16) in CELL-1/2/4, one linear part per level. Lemma GRADE
derives all six numbers and the level/node-independence in closed form.

**2.4 Lemma INJ (injectivity of T_x).** For every x ∈ Λ, T_x : 𝒞 → O^m is injective.

*Proof.* T_x factors as (per-block basis change) ∘ (full multi-Sylvester of the monic
tuple (P_p(x_p))_p, Q(x_a)). The per-block change is triangular with diagonal
π^{k_p(μ_p−j)} ≠ 0 on child blocks (A2) and identity on the cofactor block, hence
injective. The full multi-Sylvester of pairwise coprime-after-localization monic
polynomials over the fraction field is injective because each pairwise resultant is
nonzero: for p ≠ p', the reductions at the common scale are powers of distinct linear
factors (distinct frames: k ≠ k' gives distinct root valuations k, k'; k = k' gives
distinct root residues z ≠ z'), and Res(P_p, Q) ≠ 0 since... (careful honesty note:
nonvanishing of the child–child resultants follows from the valuation formulas GR-4a/b
once landed; unconditionally, it follows from the root-valuation/residue separation just
cited, which is the easy finiteness half of GR-4 and is re-proved as Lemma R below.)

**Lemma R (resultant nonvanishing, self-contained).** Work in an algebraic closure of

v(θ − ŵ_pπ^{k_p}) > k_p; hence v(θ) = k_p exactly and θ/π^{k_p} ≡ z_p in the residue
field of the extension. Two roots θ, θ' of distinct-frame factors therefore differ:
k ≠ k' ⟹ v(θ) ≠ v(θ'); k = k', z ≠ z' ⟹ (θ − θ')/π^k has nonzero residue z − z'.
Roots of Q(x_a) satisfy v(root) > 0 = v(unit)·(monic X^r + 𝔪-low coefficients: its

has valuation exactly k_p — in all cases θ ≠ root. So all pairwise resultants are
products of nonzero root differences: nonzero. ∎ (This also RE-PROVES, en passant, the

## 3. II-a: the one-grade lifting theorem (PROVED — map row GR-9)

Fix a monic degree-m target lift F ∈ O[X] (only F mod π^N matters; F ranges over pinned
lifts of target classes). For 1 ≤ n ≤ N define the level-n fibre

    S_n(F) := { x ∈ Λ/π^n Λ : Φ(x) ≡ F (mod π^n) },

well-defined by FE. Truncation maps S_{n+1}(F) → S_n(F). S_1(F) is the single all-zero
class if F ≡ X^m (mod π) (equivalently F's low coefficients are in 𝔪), and empty
otherwise; every genre target has nonempty S_N (landed `exists_peel_finset` packaged as
GR-11), hence F_c ≡ X^m (mod π) for genre classes.

**3.1 Definition (obstruction class).** For x ∈ S_n(F), n < N, choose any lift
x̂ ∈ Λ of x and set

    ω_n(x) := [ (F − Φ(x̂))/π^n  mod π ]  ∈  V := 𝔽^m / W.

Well-defined: (F − Φ(x̂)) ≡ 0 (mod π^n) since x ∈ S_n(F); replacing x̂ by x̂ + π^n δ
changes the digit by T_x(δ) mod π = T̄(δ) ∈ W (FE for the error, GRADE for the image). ∎

**3.2 THEOREM II-a (one-grade 0/K dichotomy).** Let 1 ≤ n < N, x ∈ S_n(F). Then

    #{ x' ∈ S_{n+1}(F) : trunc x' = x } = K·[ω_n(x) = 0],   with  K = q^s = q^{Σ_p μ_p}.

Moreover the set of lifts, when nonempty, is the coset structure: choosing x̂ and writing
lifts as x̂ + π^n(u,v) with (u,v) ∈ 𝔽^{s+r}, the solution set is
{(u, v*) : u ∈ 𝔽^s} for the unique v* with Σ v*_c X^{s+c} = (F − Φ(x̂))/π^n mod π — an
affine translate of ker(T̄), NOT canonically a subgroup of anything, and NOT the
nonlinear-fibre delta set (the CELL-2 separator stands; no set identification is made).

*Proof.* Lifts of x in Λ/π^{n+1} are exactly the classes x̂ + π^n(u,v), (u,v) ∈ 𝔽^{s+r}
(distinct digits give distinct classes). By FE (i = n, error ≥ 2n+1 ≥ n+1):
Φ(x̂ + π^n(u,v)) ≡ Φ(x̂) + π^n T̄(u,v) (mod π^{n+1}). The lift lies in S_{n+1}(F) iff
T̄(u,v) = (F − Φ(x̂))/π^n mod π. By GRADE this is solvable iff the right side lies in W,
i.e. iff ω_n(x) = 0, and then the solutions are v = v* unique, u free: exactly q^s. ∎

## 4. II-b: the pushforward invariant and what it buys (reductions PROVED)

**4.1 Definition (the invariant).** For 1 ≤ n < N and a monic target lift F with
S_n(F) ≠ ∅, let ω_n be as in 3.1 and

    U(n | F)  :≡  the fibres of ω_n : S_n(F) → V all have one cardinality
                  (ω_n is uniform on its image);
    I_n(F)    :=  #image(ω_n on S_n(F)).

U(n|F) and I_n(F) depend on F only through F mod π^n.

**4.2 THEOREM (aggregate law).** Fix F and n < N with S_n(F) ≠ ∅. For a lift
F' ≡ F (mod π^n), set ξ(F') := [(F' − F)/π^n mod π] mod W ∈ V; every element of V arises
this way, and F' is determined mod π^{n+1} by ξ(F') up to W-translates which have EQUAL
level-(n+1) counts. Then

    ω_n^{F'} = ω_n^{F} + ξ(F')      (global translation), hence
    #S_{n+1}(F') = K · #(ω_n^F)^{-1}(−ξ(F')).

Consequently: U(n|F) holds **iff** all reachable lifts F' of F receive the same count
#S_{n+1}(F') = K·#S_n(F)/I_n(F) — the battery's `(GR-10 mechanism)` check verbatim
(`out_DEC5R_battery.log:49/:66/:75`), including the support accounting: the number of
reachable next targets is q^r · I_n(F) (each ω-class is a W-coset of q^r target lifts).

*Proof.* The translation identity is immediate from Definition 3.1. Theorem 3.2 gives
#S_{n+1}(F') = K·#{x ∈ S_n(F) : ω_n^{F'}(x) = 0}. Uniform fibres ⟺ uniform nonzero
counts over the image, with the image swept exactly by the reachable ξ. ∎

**4.3 COROLLARY (count recursion).** If U(n|F) holds for all 1 ≤ n < N and S_N(F) ≠ ∅,
then

    #S_N(F) = q^{s(N−1)} / ∏_{n=1}^{N−1} I_n(F).                                   (4.1)

*Proof.* #S_{n+1}(F) = K·#S_n(F)/I_n(F) at each level (0 ∈ image since the tower is
nonempty up to N), #S_1 = 1, K = q^s. ∎

Worked instances (predictions of (4.1) against the battery leaf counts, using the I_n
read from the aggregate supports divided by q^r):
CELL-1 (q=2, s=2, r=1, N=5): I = (1,1,2,4): 2^8/2^3 = 32 ✓ (`log:50`).
CELL-2 (q=3, s=4, r=0, N=5): I = (1,3,9,27): 3^16/3^6 = 59049 ✓ (`log:67`).
CELL-4 (q=2, s=4, r=0, N=7): I = (1,2,4,4,8,8): 2^24/2^11 = 8192 ✓ (`log:76`).

**4.4 The remaining task, exactly.** By 4.2/4.3 and GR-11 (landed `exists_peel_finset`
packaging: every genre class has a nonempty tower), the signed count reduces to:

* **(MLIFT-1) = U(n|F_c)** for every genre class c and every n < N; and
* **(MLIFT-2, the schedule)** I_n(F_c) is one function I_n(L, D, N, r) of the genre data.

Then #Pres(c) = q^{s(N−1)}/∏ I_n — positive, genre-determined. §5 proves MLIFT-1 for

## 5. The tower reduction and the unconditional range (PROVED)

**5.1 Lemma (second-grade map).** Define T⁽²⁾ : 𝔽^s → 𝔽^m by
T⁽²⁾(u) := [T_x(u,0)/π mod π] for any x ∈ Λ (well-defined: T_x(u,0) ∈ πO[X] by (A2);
x-independent by DS mod π²). Explicitly, from (1.5) mod π²:

    T⁽²⁾(u) = σ(u) · X^{m−1},    σ(u) := Σ_{p : k_p = 1} u_{p, μ_p − 1}.

In particular L̄ := [T⁽²⁾ mod W] : 𝔽^s → V has rank ≤ 1, and L̄ = 0 whenever r ≥ 1
(X^{m−1} ∈ W) or no frame has slope 1.

*Proof.* Mod π², every term of (1.5) with a λ(x)-factor dies ((A2) + coordinates in 𝔪
give content ≥ 2), leaving Σ_{p,j} u_{p,j}E_{p,j}∏_{β'≠p}C_{β'}. By (A2) the column
E_{p,j} survives mod π² only for k_p(μ_p−j) = 1, i.e. k_p = 1, j = μ_p−1, where
E/π ≡ X^{μ_p−1} and ∏C_{β'} ≡ X^{m−μ_p} (A3). ∎

**5.2 Tower lemma (finite bookkeeping).** Let f : A → V with A finite, V a finite
abelian group. Suppose A = ⊔_{y∈B} A_y with all #A_y = K, and on each A_y, f is a
surjection onto a coset c_y + V₀ of ONE fixed subgroup V₀ ≤ V with all fibres of size
K/#V₀. Then f is uniform on its image iff ḡ : B → V/V₀, y ↦ c_y + V₀, is uniform on its
image; and #image(f) = #V₀ · #image(ḡ). *Proof.* #f^{-1}(ξ) = (K/#V₀)·#ḡ^{-1}(ξ mod V₀)
for every ξ ∈ image(f). ∎

**5.3 THEOREM (tower reduction).** Let n ≥ 2, S_n(F) ≠ ∅. Write
Live_{n−1}(F) := (ω_{n−1})^{-1}(0) ⊆ S_{n−1}(F). For y ∈ Live_{n−1}(F) choose a lift ŷ
and let x₀(y) := ŷ + π^{n−1}(0, v*) with v* as in Theorem 3.2, so that the K-fibre of
S_n(F) over y is {x₀(y) + π^{n−1}(u,0) : u ∈ 𝔽^s}. Then

    ω_n( x₀(y) + π^{n−1}(u,0) ) = ω_n(x₀(y)) − L̄(u),

and hence (by 5.2, with V₀ = image L̄ fixed by 5.1): U(n|F) holds iff
ḡ_n : Live_{n−1}(F) → V/image(L̄), y ↦ ω_n(x₀(y)) mod image(L̄), is uniform on its
image. ḡ_n is independent of the choices (changing ŷ or v*-conventions moves
ω_n(x₀(y)) by elements of W + image(T⁽²⁾), hence fixes ḡ_n).

*Proof.* FE at i = n−1: Φ(x₀ + π^{n−1}(u,0)) ≡ Φ(x₀) + π^{n−1}T_{x₀}(u,0)
(mod π^{2n−1}), and 2n−1 ≥ n+1 for n ≥ 2. The middle term contributes to digit n exactly
