There is no proposed equality between a `GaugeLattice` element and a `Polynomial O`.
The dictionary is the equality of their **scalar reads**.  Keep D.44's abstract
`N : NormSection G` and `R : G → Kt` in the standalone law:

* `EFF.T3.21` first pins `q = u_{i+1}`, `N(q) = n̂_i(u_{i+1})`, and
  `N(sq) = n̂_i(su_{i+1})`, then defines
  `w_i = R_{i+1,k̄_i}(n̂_i(u_{i+1}))`.  Thus the source bridge is at the read-value
  surface, not an equality of the two carrier types.
* GENTOW2 S5.2 lines 729–752 takes
  `w := u(k̄) = R_{3,k̄}(n̂₂(u₃))` and proves the peel identity from it.  The object read
  on the polynomial side is therefore exactly the below-current-key normalizer.
* OPEN-DICT-2 fixed that normalizer at repo depth `r > 0` as
  `chainNormBelow I r k = chainNorm I (r - 1) k`, and fixed the honest read grade as the
  full-current coordinate `e' * (s * u')`.  No `chainNorm r` or uncleared grade is allowed.
* `C130vw.GaugeFamilyViewEq` already pins an arising witness's exported `N.n` to the
  transported `arenaNormSection0.n`; `ArenaFamilyViewEq` pins `R j` on live indices to
  the same witness's `towerRead`.  Replacing the law's `N` by a concrete

### [GCW-0] Exact `GC13Wiring` statement

This is the Lean-ready, elaboration-checked statement.  `A` is intentionally absent: the
remaining GC-13 read dictionary uses only D.44's `N`, `q`, and `R`; the already-discharged
theta dictionary is separate.

```lean
universe uT

/-- GC-13's read/normalizer dictionary at one D.44 site. -/
structure GC13Wiring {G : Type*} [CommGroup G] {Kt : Type*} [Field Kt]
    (N : NormSection G) (q : ℤ) (R : G → Kt)
    {O : Type} [CommRing O] [IsDomain O] [IsDiscreteValuationRing O] {π : O}
    {F : KeyFrame O π} {H₀ : ℕ} {hpin : F.Pin H₀} {r : ℕ}
    {W : DeepTower.{0, uT} F H₀ hpin r} {e' f' u' : ℕ}
    (I : FGMNCalculus W e' f' u') (φ : W.fld r →+* Kt) : Prop where
  read_norm : ∀ s : ℕ, 1 ≤ s → s ≤ f' →
    R (N.n (s * q)) =
      φ (I.Rgr (e' * (s * u')) (I.chainNormBelow r (s * u')))
```

The grade is deliberately `e' * (s * u')` (OPEN-DICT-2 full-current clearing), and the
normalizer is deliberately `chainNormBelow r` (the decided `n̂_i`, not the current key).
