## §5. Proof of S2 (the CRT unit pivot) and the span decomposition

LEMMA S2. κ a field, f_1,…,f_s ∈ κ[Y] monic, pairwise coprime, g ∈ κ[Y] nonzero
with gcd(g, f_i) = 1 for all i. Then the ḡ-system
  { (Y-shifted) δ_i·F̄_i·g : deg δ_i < deg f_i },  F̄_i := ∏_{i'≠i}f_{i'},
is linearly independent: if Σ_i δ_i F̄_i g = 0 then all δ_i = 0.
Proof. Reduce mod f_i: every term with i' ≠ i contains f_i, so δ_i F̄_i g ≡ 0
(mod f_i). F̄_i g is invertible mod f_i (coprimality), so f_i | δ_i, and
deg δ_i < deg f_i forces δ_i = 0. ∎

COROLLARY S2' (span decomposition). With Φ̄ := ∏_i f_i, n := Σdeg f_i, and any
r' ≥ 0 with deg g ≤ r':
  κ[Y]_{< n+r'} = span{ (Y−root-basis) δ_iF̄_ig } ⊕ span{ Y^jΦ̄ : j < r' } ,
and the first summand has dimension n. Proof. Independence of the first: S2.
Independence of the union: Σδ_iF̄_ig = c·Φ̄ (deg c < r') reduces mod f_i to
δ_iF̄_ig ≡ 0, so δ_i = 0 as above, then cΦ̄ = 0 forces c = 0. Dimensions:
n + r' = dim. ∎
Consequently every element of κ[Y]_{<n+r'} — in particular each monomial Y^i,
i < n — has a unique expression ĝ_i + c̄_iΦ̄ with ĝ_i in the ḡ-span; comparing
degrees, deg(c̄_iΦ̄) ≤ max(i, s-part) gives deg c̄_i ≤ deg g − 1 whenever i < n
(the ḡ-span lives in degrees ≤ n − 1 + deg g). This degree bound is the
lattice-validity workhorse of §6.
## §6. THEOREM E — the equal-slope regime, completely identified (PROVED)

THEOREM E. Let all children share one slope k (distinct residues z_p ≠ 0), with
an admissible cofactor of degree r ≥ 0. Put β := β_k, D := k·s_μ + β = the genre
content, ε := 1+D, δ_j := 1+k(s_μ+j). Then the Smith exponents of the restricted
multi-Sylvester matrix A are EXACTLY the multiset

    { ε − k·i : 0 ≤ i < s_μ }  ∪  { 1 }^r ,

for EVERY admissible base presentation; the truncated (mod π^N) invariant list is
the entrywise min with N. This is C2 with one block, and matches every observed
equal-slope cell (§2).

Proof. Work at scale k (§4). Smith exponents of A = elementary divisors of the
lattice pair (Θ, M), Θ := ⊕_{i<m} O·π^{ki}Y^i, where M is generated by
  u_{p,j} := π^ε·g_{p,j},   g_{p,j} := (Y−ẑ_p)^j·F̃_p·Q̃    (child columns), and
  v_j     := π^{δ_j}·h_j,   h_j := Y^j·Φ̃, Φ̃ := ∏_p P̃_p     (cofactor columns);
all contents exact by S1(vi) (single block: every child column extracts ε), the
g's of content 0, h_j MONIC of degree s_μ+j. Determinantal ideals are invariant
under GL_m(O) changes of the generating set and of the Θ-basis.

Step 1 (residue normal form). Reductions: ḡ_{p,j} = (Y−z_p)^j·F̄_p·Q̄ with
F̄_p = ∏_{p'≠p}(Y−z_p')^{μ_{p'}}, and Q̄ ≠ 0 of degree d, Q̄(z_p) ≠ 0
(root-freeness), β ≥ k·d (S1(v)). By S2' (f_p := (Y−z_p)^{μ_p}, g := Q̄, r' := r):
κ[Y]_{<m} = span{ḡ} ⊕ span{Y^jΦ̄}_{j<r}. Hence for each i < s_μ there are unique
λ̄^{(i)} and c̄_i with  Y^i = Σ λ̄^{(i)}_{p,j}·ḡ_{p,j} + c̄_i·Φ̄,  deg c̄_i ≤ d−1
(degree comparison, §5). The s_μ × s_μ matrix (λ̄^{(i)}) is invertible over κ
(it expresses the basis {Y^i mod U} through the basis {ḡ mod U} of the quotient).

Step 2 (lift and clear the junk). Lift λ̄, c̄_i to O (choosing c_i ∈ O[Y]_{<d}) and
set w'_i := Σλ^{(i)}g_{p,j} − c_i·Φ̃, so w'_i ≡ Y^i mod π. Junk coefficients of
w'_i at abscissa s_μ+j (0 ≤ j < r): from the g-part, the Q̃-factor must sit at
abscissa ≥ j+1, and v(coeff_a(Q̃)) ≥ ka−β for all a, so the coefficient has
v ≥ k(j+1)−β = (δ_j − ε) + k; from the c_iΦ̃-part, nonzero only for j ≤ d−1 where
δ_j − ε = kj−β ≤ k(d−1)−β ≤ −k < 0. In both cases the coefficient is divisible

v_j (top abscissa first, j = r−1 down to 0; each subtraction only lowers the
remaining junk abscissae and preserves the divisibility invariant, since h_j is
monic at s_μ+j) kills every coefficient at abscissae ≥ s_μ. Result:
  u_i := π^ε·(Y^i + π·J_i),  J_i ∈ O[Y]_{<s_μ},  for i = 0..s_μ−1.
The passage [child gens | cofactor gens] → [u | v] is the block matrix
[[Λ, 0], [−C, I]] with Λ ≡ (λ̄) mod π invertible and C ∈ O-entries (that is what
the divisibility bounds certify), hence lies in GL_m(O).

Step 3 (the matrix and its ideals). In the Θ-basis, the new generator matrix W:
  child col i (i < s_μ):  W[i][i] = π^{ε−ki}·unit;  W[i'][i] ∈ π^{ε−ki'+1}O for
