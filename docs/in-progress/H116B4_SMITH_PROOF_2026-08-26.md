## §5. Proof of S2 (the CRT unit pivot) and the span decomposition

LEMMA S2. κ a field, f_1,…,f_s ∈ κ[Y] monic, pairwise coprime, g ∈ κ[Y] nonzero
with gcd(g, f_i) = 1 for all i. Then the ḡ-system
  { (Y-shifted) δ_i·F̄_i·g : deg δ_i < deg f_i },  F̄_i := ∏_{i'≠i}f_{i'},
is linearly independent: if Σ_i δ_i F̄_i g = 0 then all δ_i = 0.
Proof. Reduce mod f_i: every term with i' ≠ i contains f_i, so δ_i F̄_i g ≡ 0
(mod f_i). F̄_i g is invertible mod f_i (coprimality), so f_i | δ_i, and
deg δ_i < deg f_i forces δ_i = 0. ∎

COROLLARY S2' (span decomposition). With Φ̄ := ∏_i f_i, n := Σdeg f_i, and any
r' ≥ 0 with deg g ≤ r':
  κ[Y]_{< n+r'} = span{ (Y−root-basis) δ_iF̄_ig } ⊕ span{ Y^jΦ̄ : j < r' } ,
and the first summand has dimension n. Proof. Independence of the first: S2.
Independence of the union: Σδ_iF̄_ig = c·Φ̄ (deg c < r') reduces mod f_i to
δ_iF̄_ig ≡ 0, so δ_i = 0 as above, then cΦ̄ = 0 forces c = 0. Dimensions:
n + r' = dim. ∎
Consequently every element of κ[Y]_{<n+r'} — in particular each monomial Y^i,
