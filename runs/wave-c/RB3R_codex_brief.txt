## The definitions (verbatim from the corpus)

`dev φ f j` is the j-th digit of the φ-adic expansion of f (iterated monic
divByMonic/modByMonic: `dev φ f 0 = f %ₘ φ`, `dev φ f (j+1) = dev φ (f /ₘ φ) j`).
It is unconditionally additive in f for monic φ (landed: `dev_add_of_monic`, `dev_sub`).

```lean

        = L.r.coeff t))

def towerSolve (u e k : ℕ) : ℕ :=
  ((List.range e).find? (fun b => (b * u) % e == k % e)).getD 0

-- F.slotIdx k : the unique i < e₁ with i·h ≡ k (mod e₁) (spec landed: slotIdx_spec).

  ∑ r ∈ Finset.range F.f₁, ∑ t ∈ Finset.range T.f₂,
    Polynomial.C
        (resLift (F.stageCoord H₀ hpin (k2Coord T s t) r)
          * π ^ (n2Exp T (m - (F.e₁ * T.e₂ * F.h * r + T.e₂ * T.u₂ * t))).1)
      * Polynomial.X
          ^ ((n2Exp T (m - (F.e₁ * T.e₂ * F.h * r + T.e₂ * T.u₂ * t))).2.1 + F.e₁ * r)
      * F.key ^ ((n2Exp T (m - (F.e₁ * T.e₂ * F.h * r + T.e₂ * T.u₂ * t))).2.2 + T.e₂ * t)
-- resLift : lift of a residue-field element to O, with resLift 0 = 0 and
-- residue (resLift x) = x (so resLift x ≠ 0 when x ≠ 0). stageCoord reads the η-basis
-- coordinates of an element of K over the residue field; all coordinates of a nonzero
-- element are not all zero, and stageCoord of 0 is 0.
```

CLAIM 2 (digit support of the lift). Each (r,t) term of k2DigitLift T s lam is
C(c)·X^(i+e₁r)·F.key^(b₀+e₂t) with i + e₁r < D′ (via slotIdx_spec), so the F.key-digit

resLift(stageCoord (k2Coord T s t) r) · π^{a₀} = 0 for all r, iff k2Coord T s t = 0.

CLAIM 3 (clause-4 failure at e₂ ∤ lam). If e₂ ∤ lam then b₀ ≠ 0 and each abscissa
