### Hit predicate

An unordered pair \(\{r,s\}\) is a hit exactly when:

\[
\begin{aligned}
&\mathcal F(r)=\mathcal F(s),\\
&f_r\neq f_s \quad\text{as exact polynomials},\\
&H(r)=H(s) \quad\text{field by field},\\
&T(r)\neq T(s).
\end{aligned}
\]

Equivalently in pseudocode:

```text
for each same-frame pair (r, s), r < s:
    if exact_polynomial(r.f) == exact_polynomial(s.f):
        continue
    if r.pins              != s.pins:              continue
    if r.deciding_residues != s.deciding_residues: continue
    if r.honest_sigma      != s.honest_sigma:      continue
    if r.honest_labels     != s.honest_labels:     continue
    if r.shadow_at_or_above_theta == s.shadow_at_or_above_theta:

    emit HIT(r, s)
```

### Why a hit is a complete proof

Suppose shadow content were a function \(F\) of the full verdict-level honest output. A hit supplies

\[

\]

Functionality would give \(T(r)=F(H(r))=F(H(s))=T(s)\), a contradiction. Exact reader evaluation plus the printed first differing digit is therefore a finite proof, not merely statistical evidence.
