## What is refuted

`leanspec/Leanspec/ChapB.lean`, **B.39** `exists_graded_solve`, **as re-signed by amendment
A-F.8** (commit c25c28f1; blueprint `CHAP-B_leaf_layer.md` NODE B.39):

```lean
axiom exists_graded_solve (hπ : Irreducible π) {φ : Polynomial O} (hφ : IsKey φ)
    {u ℓ : ℕ} (hu : 0 < u) (hℓ : 0 < ℓ) (hcop : Nat.Coprime u ℓ) {g h : Polynomial O}
    (hg : g.Monic) (hh : h.Monic)
    (hgd : φ.natDegree ∣ g.natDegree) (hhd : φ.natDegree ∣ h.natDegree)
    (hgh : GradedCoprime π φ u ℓ g h)
    {c : ℕ} {e : Polynomial O} (hdeg : e.natDegree < (g * h).natDegree)
    (he : ((c : ℕ) : ℕ∞) ≤ suppVal φ e u ℓ) :
    ∃ U V : Polynomial O, U.degree < g.degree ∧ V.degree < h.degree ∧
      ((c + 1 : ℕ) : ℕ∞) ≤ suppVal φ (e - (h * U + g * V)) u ℓ
```

A-F.8 repaired the *shape* of the two conclusion bounds (`natDegree` → `degree`), which was
right; but the signature has a **third, independent defect that neither A-F.6 nor A-F.8
touched**: nothing relates the weight `c` to the weights of `g` and `h`.

`b39_signature_refuted_level` below produces, at **any** DVR `O`, **any** uniformizer `π` and
**any** key `φ`, at `u = ℓ = 1` (so `hu`, `hℓ`, `hcop` hold), a witness satisfying every
hypothesis whose conclusion is **false**:

* `g := φ + C π`  — monic of degree `m`, `(1,1)`-pure, `sideDeg = 1`,
  `suppVal φ g 1 1 = 1`, residual polynomial `1 + Y`;
* `h := φ * g + C (π ^ 2)` — monic of degree `2m`, `(1,1)`-pure, `sideDeg = 2`,
  `suppVal φ h 1 1 = 2`, residual polynomial `1 + Y + Y ^ 2`;
* `GradedCoprime` is discharged by the **explicit Bézout certificate**
  `(-Y) * (1 + Y) + 1 * (1 + Y + Y ^ 2) = 1`, valid over any ring — no residue-characteristic
  assumption is needed anywhere in this file;
* `e := 1`, `c := 0`.

## Why the conclusion fails

`h * U + g * V = φ * (g * U + V) + C π * (C π * U + V)` identically, so **every** value of the
solve operator lies in the ideal `(φ, π)`, whereas `e = 1` does not.  Concretely
`dev φ (1 - (h*U + g*V)) 0 = 1 + (C π * W) %ₘ φ` with `W := −(C π * U + V)`, whose constant
coefficient is `1 + π·(…)`, a unit.  So `npHgt φ (e − (h*U + g*V)) 0 = 0` and the support value
is `0`, never `≥ c + 1 = 1`.  The degree bounds on `U`, `V` are not even used: **no** `U`, `V`
whatsoever work.

## Root cause

B.39's PROOF step 3 assembles the lift as
`U := Σ_k (lift of U₀'s k-th coefficient) * π^{(line height)} * φ^{j₀ + ℓ k}`
and never checks that **the line height is a natural number**.  The level-`c` line of slope
`−u/ℓ` has lattice points `(j* + ℓk, H* − u·k)` where `j* < ℓ` is the least abscissa in the
class of `c` mod `ℓ` and `ℓ·H* = c − u·j*`.  The solve needs `a` lattice slots for `U` and `b`
for `V`, i.e. `H* ≥ u·b + u·(a−1)` and `H* ≥ u·a + u·(b−1)`, i.e. `H* ≥ u·(a+b−1)`.  At
`c = 0` there is **one** slot in total, and it is already spoken for by `g` and `h`
themselves: the graded piece at level `0` is not in the image of the solve operator at all.

## The repair (verified, not merely proposed)

**(R3)** add the level hypothesis

```lean
    (hc : suppVal φ (g * h) u ℓ ≤ ((c : ℕ) : ℕ∞))
```

equivalently `u * ℓ * (a + b) ≤ c` where `a`, `b` are the two residual degrees.  This is exactly
what makes the height bookkeeping honest, and it is **sufficient**: with `j* ≤ ℓ − 1` and
`ℓ·H* = c − u·j* ≥ u·ℓ·(a+b) − u·(ℓ−1) = ℓ·u·(a+b−1) + u`, one gets `H* > u·(a+b−1)`, so every
lattice slot the residual Bézout solve can use has a nonnegative height.

*It is free at the only consumer.* B.41's iteration calls B.39 at
`c_k = suppVal φ f u ℓ + k + 1` and `f = g_k · h_k` with `suppVal φ (g_k h_k) u ℓ =
suppVal φ f u ℓ` (B.35's `suppVal_mul_eq_of_pure`, landed), so
`suppVal φ (g_k h_k) u ℓ = c_k − k − 1 < c_k`.  B.41's own signature is unaffected.

*It is not implied by anything already present.* `hdeg` bounds `e`'s **degree**, not its weight;
`he` bounds `e`'s weight from below by `c` but says nothing about `g`, `h`.  The witness below
has `suppVal φ (g*h) 1 1 = 3` and `c = 0`.

## What is NOT impugned

`hu`/`hgd`/`hhd` (A-F.6) and the `degree` form of the conclusion (A-F.8) all survive: they are
independent defects, all three real.  The route (residual Bézout + `resLift`) is untouched, and
the general graded product law it needs is now landed
(`Uniformity/ChapB/B39a.lean`: `resMk_dev_mul_gen`, `resPoly_mul_gen`, …).
-/

/-- Auxiliary: on a side of finite support value, an on-side abscissa of a polynomial of degree
`n * φ.natDegree` is at most `n`. -/
private theorem le_of_mem_sideSet_aux {φ : Polynomial O} (hφ : φ.Monic) (hd : 0 < φ.natDegree)
    {w : Polynomial O} {n : ℕ} (hwdeg : w.natDegree = n * φ.natDegree)
    (htop : suppVal φ w 1 1 ≠ ⊤) {j : ℕ} (hj : j ∈ sideSet φ w 1 1) : j ≤ n := by
  have hon := onSide_of_mem_sideSet hj
  have hne : npHgt φ w j ≠ ⊤ := npHgt_ne_top_of_onSide one_pos htop hon
  have hdev : dev φ w j ≠ 0 := fun hz => hne (npHgt_eq_top_iff.2 hz)
  by_contra hcon
  refine hdev (dev_eq_zero_of_lt hφ hd w j ?_)
  rw [hwdeg]
  exact mul_lt_mul_of_pos_right (by omega) hd

        refine le_trans ?_ (gaussVal_le_modByMonic hπ hφ.monic _)
        rw [gaussVal_mul hπ, hgvπ]
        exact le_self_add
      have := (le_gaussVal_iff hπ (k := 1)).1 (by exact_mod_cast hval) 0
      rwa [pow_one] at this
    rw [hmod, Polynomial.coeff_add, Polynomial.coeff_one_zero] at hdvd1
    exact hπ.not_isUnit (isUnit_of_dvd_one (by simpa using Dvd.dvd.sub hdvd1 hdvd2))
