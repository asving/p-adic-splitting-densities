## The defect, exactly

Two independent slacknesses combine in the `refine` constructor of `DescentStep`:

1. **`sideSet` is ALWAYS nonempty.** `sideSet φ f u ℓ` (B.16) is the argmin set of a
   `Finset.inf` taken over `Finset.range (f.natDegree + 1)`, which is nonempty, so the `inf` is
   attained. The repo already owns the proof: `Uniformity.Density.Leaf.sideSet_nonempty_gen`
   (`Uniformity/ChapB/B39b.lean:679`), landed and Lean-core. Hence the two clauses
   `(sideSet s.key s.block u ℓ).Nonempty` and `(sideSet s'.key s.block u' ℓ').Nonempty` of the
   `refine` constructor are **vacuous** — they constrain nothing, and in particular they do NOT
   assert that `(u, ℓ)` or `(u', ℓ')` is an attained *side* of a real polygon. This is exactly
   the defect already recorded for NODE C.113 clause (i) (`C113_REFUTATION.lean.txt`); C.94
   repeats it, twice.
2. **The recentering clause admits `s' = s`.** `(s.key - s'.key).natDegree < s.key.natDegree`
   is meant to say "recentering by a strictly lower-degree perturbation", but at `s' = s` the
   perturbation is `0`, `natDegree 0 = 0`, and the clause reads `0 < s.key.natDegree` — true
   for every key of positive degree.

Consequently `DescentStep π s s` holds for **every** state `s` with `0 < s.key.natDegree`
(take `(u, ℓ) = (0, 1)`, `(u', ℓ') = (1, 1)`, so `u * ℓ' = 0 < 1 = u' * ℓ`), the constant
history `hist n = s` is an infinite `DescentStep`-chain on a fixed monic squarefree `f`, and
`NS7TerminationStatement` delivers `False`. The blueprint's own gloss — *"the slope-increase
clause is what makes vacuous refine loops non-steps"* — is precisely the claim that fails: the
slope-increase clause compares two slopes of the SAME polygon when `s' = s`, and every pair of
distinct slopes is available because `sideSet` never empties.

`f = X` suffices as the monic squarefree witness (`Polynomial.irreducible_X.squarefree`), and
`s = ⟨X, X⟩` has `s.key.natDegree = 1 > 0`, so the counterexample needs no arithmetic at all.

## What is NOT claimed

That the cited theorem is false. [AGNPRW] (Found. Comput. Math. **25** (2025) no. 2, 631-681,
DOI 10.1007/s10208-024-09646-x, **Thm 5.6** — the A-3 numbering correction of
`docs/CITE_NUMBERING_AUDIT_2026-08-16.md` §3, the repo's "Thm 5.2" being the arXiv-v1 number
that collides with a different published theorem) is a true termination theorem about OM
descent. What is refuted is **this transcription of it**: `DescentStep` is a strictly larger
relation than §5's descent grammar, so "no infinite `DescentStep`-history" is strictly stronger
than what [AGNPRW] proves, and is false.

## Repair direction (NOT applied here — the statement is frozen and owner-signed at category)

The `refine` constructor needs the two side clauses replaced by genuine side data, and the
self-loop excluded. Minimally: (a) require `s' ≠ s` (or `s'.key ≠ s.key`); (b) replace
`(sideSet _ _ u ℓ).Nonempty` by an attainment clause with content — e.g.
`1 < (sideSet s.key s.block u ℓ).card`, the two-point-side predicate B.42 clause 5 uses, or
`0 < sideDeg …`; (c) pin `(u, ℓ)` coprime and above the frame floor, as C.33's `hslopes` does.
Any repair is a STATEMENT CHANGE and must go back through gate (b).

variable {O : Type*} [CommRing O] [IsDomain O] [IsDiscreteValuationRing O] {π : O}

/-! ## 1. The A-C.1 carriers, transcribed verbatim from `leanspec/Leanspec/ChapC.lean` -/

/-- the §5 descent state: the current key and the current block factor. -/
structure DescentState (O : Type*) [CommRing O] where
  key : Polynomial O
  block : Polynomial O

/-- one step of §5's descent grammar (the [AGNPRW]-consumed shape). -/
inductive DescentStep (π : O) : DescentState O → DescentState O → Prop
  | jump : ∀ {F : KeyFrame O π} {H₀ : ℕ} {hpin : F.Pin H₀} (L : LevelDatum F H₀ hpin)
      (s s' : DescentState O),
      s.key = F.key → 2 ≤ L.ℓ * L.r.natDegree →
      HasLabel L s'.block → s'.block ∣ s.block →
      IsTestKey L s'.key → L.keyDeg₂ * 2 ≤ s'.block.natDegree →
      DescentStep π s s'
  | refine : ∀ (s s' : DescentState O) (u ℓ u' ℓ' : ℕ),
      0 < ℓ → 0 < ℓ' → s'.block = s.block →
      s'.key.natDegree = s.key.natDegree →
      (s.key - s'.key).natDegree < s.key.natDegree →
      (sideSet s.key s.block u ℓ).Nonempty →
      (sideSet s'.key s.block u' ℓ').Nonempty →
      u * ℓ' < u' * ℓ →
      DescentStep π s s'

/-- NODE C.94's EXACT LEAN STATEMENT as drafted. -/
def NS7TerminationStatement : Prop :=
  ∀ (O : Type) [CommRing O] [IsDomain O] [IsDiscreteValuationRing O]
    [IsAdicComplete (IsLocalRing.maximalIdeal O) O]
    [Finite (IsLocalRing.ResidueField O)] (π : O), Irreducible π →

    ∀ hist : ℕ → DescentState O,
      (∀ n, (hist n).block ∣ f) →
      (∀ n, DescentStep π (hist n) (hist (n + 1))) → False

/-! ## 2. The self-loop -/

/-- **The step relation has a self-loop at every state of positive key degree.** -/

    DescentStep π s s := by
  refine DescentStep.refine s s 0 1 1 1 Nat.one_pos Nat.one_pos rfl rfl ?_
    (sideSet_nonempty_gen _ _ _ _) (sideSet_nonempty_gen _ _ _ _) (by omega)
  simpa using h
