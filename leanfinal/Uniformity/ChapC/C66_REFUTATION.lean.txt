## The defect, exactly: `IsDvPure` is VACUOUS below the frame degree

`IsDvPure F g u ℓ` (C.29) is

```lean

```

and the second conjunct uses **`ℕ`-division**. For `0 < g.natDegree < D′` it floors to `0`, so
the two conjuncts coincide and "purity" degenerates to "`0` is on the side" — which holds for
every `(u, ℓ)` as soon as `dev F.key g 0 ≠ 0` and `dev F.key g j = 0` for `j ≥ 1`, i.e. for
every nonzero `g` of degree `< D′`. `g = X` at `D′ = 2` is the smallest instance. The cited
theorem's hypotheses are about factors of a `dv`-dissection, whose degrees are multiples of
`D′` by construction; the transcription dropped that.

This is the same class of defect as B.42's `[IsAdicComplete]` near-miss (a truth-bearing
hypothesis silently absent) and as C.113 clause (i)'s vacuous `hne`

def C66Statement : Prop :=
  ∀ (O : Type) [CommRing O] [IsDomain O] [IsDiscreteValuationRing O] (π : O)
    (F : KeyFrame O π) (_hπ : Irreducible π) (H₀ : ℕ)
    (hpin : npHgt Polynomial.X F.key
      (sideMin Polynomial.X F.key F.h F.e₁ F.hne) = (H₀ : ℕ∞))
    (g g' : Polynomial O) (_hg : g.Monic) (_hg' : g'.Monic) (u ℓ : ℕ) (_hl : 0 < ℓ)
    (_hcop : Nat.Coprime u ℓ) (_hpg : IsDvPure F g u ℓ) (_hpg' : IsDvPure F g' u ℓ)
    (hne : (dvSideSet F g u ℓ).Nonempty) (hne' : (dvSideSet F g' u ℓ).Nonempty)
    (hne'' : (dvSideSet F (g * g') u ℓ).Nonempty) (M₀ M₀' M₀'' : ℕ)
    (hp : dvHgt F g (dvSideMin F g u ℓ hne) = (M₀ : ℕ∞))
    (hp' : dvHgt F g' (dvSideMin F g' u ℓ hne') = (M₀' : ℕ∞))
    (hp'' : dvHgt F (g * g') (dvSideMin F (g * g') u ℓ hne'') = (M₀'' : ℕ∞)),
    ∃ c : F.stageField H₀ hpin, c ≠ 0 ∧
      dvResPoly F H₀ hpin (g * g') u ℓ hne'' M₀'' hp''
        = Polynomial.C c
            * (dvResPoly F H₀ hpin g u ℓ hne M₀ hp * dvResPoly F H₀ hpin g' u ℓ hne' M₀' hp')

theorem c66_refuted_at_s2Frame (hax : C66Statement) : False := by
  classical
  have hpin : (s2Frame h2 hq).Pin 1 := s2Frame_pin h2 hq
  have hpX : dvHgt (s2Frame h2 hq) (Polynomial.X : Polynomial O)
      (dvSideMin (s2Frame h2 hq) Polynomial.X 2 1 (hneX h2 hq)) = ((1 : ℕ) : ℕ∞) := by
    rw [dvsidemin_X h2 hq, dvhgt_X_0 h2 hq]; rfl
  have hpXX : dvHgt (s2Frame h2 hq) (Polynomial.X * Polynomial.X : Polynomial O)
      (dvSideMin (s2Frame h2 hq) (Polynomial.X * Polynomial.X) 2 1 (hneXX h2 hq))
        = ((2 : ℕ) : ℕ∞) := by
    rw [dvsidemin_XX h2 hq, dvhgt_XX_0 h2 hq]; rfl
  obtain ⟨c, hc, heq⟩ := hax O 2 (s2Frame h2 hq) h2 1 hpin Polynomial.X Polynomial.X
    Polynomial.monic_X Polynomial.monic_X 2 1 Nat.one_pos (Nat.coprime_one_right 2)
    (pureX h2 hq) (pureX h2 hq) (hneX h2 hq) (hneX h2 hq) (hneXX h2 hq) 1 1 2 hpX hpX hpXX
  have hRX : dvResPoly (s2Frame h2 hq) 1 hpin (Polynomial.X : Polynomial O) 2 1
      (hneX h2 hq) 1 hpX
      = Polynomial.C ((s2Frame h2 hq).twistRead 1 hpin 1
