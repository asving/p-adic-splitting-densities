## 2. NOT a re-sign: the signed binders already carry what the truth needs

The unit brief asked whether the statement needs `hz : z ≠ 0` or pairwise-distinct `z`, and
whether the signed binders carry it. **They do, implicitly, and no re-sign is warranted:**

* `HasChildAt π c μ k z` itself carries `2 ≤ μ ∧ 1 ≤ k ∧ z ≠ 0` (H.109's def half). The
  exactness clause `∀ p, HasChildAt π c p.1 p.2.1 p.2.2 ↔ p ∈ L` therefore forces every
  `p ∈ L` to satisfy those, and if `L` violates them the set is EMPTY for every `t`, so
  `F = 0` discharges the statement.
* For a FIXED `(k,z)` the multiplicity `μ` is unique — `HasChildAt`'s second and third
  clauses say `μ = min {j ∣ ¬ π^(D+1) ∣ frameⱼ}`. So `L` cannot contain two triples sharing
  `(k,z)`; if it does, empty again, `F = 0`.
* Likewise a `D` that is inconsistent (two `p ∈ L` with the same `k` but `D p ≠ D p'`) makes
  the set empty for every `t`.

Every degenerate `(L, D)` is therefore handled by `F = 0`, and every non-degenerate one is
covered by the exhaustive measurement below. **No refutation instance exists; the statement
is not the obstacle.**

## 4. Why it is BLOCKED — the four missing pieces, and the one that is a research step

### 4a. The multi-child peel (`Finset`-indexed) — node-sized, mechanical

`exists_peel` peels ONE child. The node needs
`monicPoly a = (∏_{p ∈ L} alphaParent π (b_p) k_p ẑ_p) * Q`. Induction on `L` needs the new
theorem *the cofactor inherits the remaining children* — and its degree bookkeeping
(`Σ_p μ_p ≤ m`) is not available from H.108's cap alone; §4's `μ ≤ m` argument does not
iterate.

### 4b. "Multiplicity ADDS" — node-sized, and §5 is half of it

The genre-exactness clause needs, at every frame `(k', z')`:

```
ord₀(divided frame of c)  =  ord₀(divided frame of Q)  +  Σ_{p ∈ L, (k_p,z_p) = (k',z')} μ_p
```

(`ord₀` = least index with a unit coefficient). §5's Gauss lemma is the CONTENT half of
exactly this argument; the multiplicity half is the same argument run on the divided
reduction in `(ResidueField O)[X]`, where `ord₀` of a product is the sum of the `ord₀`s.
Together with §3's unit-constant lemma (a planted factor contributes `ord₀ = 0` at every
FOREIGN frame and `ord₀ = μ` at its own) this yields the child set EXACTLY.

### 4c. `¬ IsCSState` transport — node-sized, and OUTSIDE this module's dependency set

`IsBetaState` carries `¬ IsCSState π c`. §6 transports the content and the children but not
CS: that needs the ChapB polygon API (`sideSet`, `sideMin`, `npHgt`, `resPoly`), which
`H116bR.lean` deliberately does not import. Certification check **G** measures the fact
needed (the replant difference sits strictly ABOVE the parent's full Newton polygon at every
`(u, ℓ)`); H.115b's `not_isCSState_of_alphaParent` is the α-side template.

### 4d. The COUNT — the research step. Naive route CLOSED, replacement route CERTIFIED

**Closed.** The obvious route — build `R_{t→t'} : fibre(t) → fibre(t')` by peel-shift-replant
and show it bijective — is refuted by the battery's own expected-negatives:

* **D3**: two exact planted presentations of the SAME class, shifted by the SAME `Δ`, land in
  DIFFERENT classes in same-slope multi-child genres. So `R` is well defined only from the
  CANONICAL lift, and its injectivity does NOT follow from presentation stability.
* **E3**: the round trip `R_{t→t'} ; R_{t'→t}` is NOT the identity (section carries in `Z_q`).
  So mutual injections cannot be assembled from a round trip either.
* Surjectivity of `R` (which would suffice — two surjections between finite sets force
  equicardinality) fails for the same reason: recovering a preimage requires peeling the
  canonical lift of the shifted state, and that peel differs from the shifted peel by exactly
  the amount D3 exhibits. **Confirmed closed. Assign no more agents to the replant route.**
  D1 records the one exception: presentation stability HOLDS on SINGLE-child genres.
