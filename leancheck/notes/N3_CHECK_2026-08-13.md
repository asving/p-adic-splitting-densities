## 2. THE MATHEMATICS (written before the Lean)

Write `f = monicPoly a = X³ + a₂X² + a₁X + a₀`.

**Peeling.** `typeOf` is additive on monic products because `monicFactors` is
(`monicFactors_mul` → `typeOf_mul` → `typeOf_linear_mul`, `N3Base`). So the three composite types
reduce to (linear factor) × (quadratic whose type `leanfinal` already certifies). The linear
factor comes from Hensel at a simple residue root, and dividing it out is a *`ring` identity, not
a division*:

    f(r) = 0  ⟹  monicPoly a = (X − C r) · monicPoly ![a₁ + a₂r + r², a₂ + r]     (`cubic_peel`)

with the useful corollary `a₀ = −r · g₀` (`peel_const`), which transports the exact valuation of
`a₀` onto the cofactor's constant term whenever `r` is a unit.

**`{(1,1),(1,2)}`.** `f̄ = (X − ρ̄)(X² + β̄₁X + β̄₀)` with the quadratic rootless. Then
`f̄′(ρ̄) = ρ̄² + β̄₁ρ̄ + β̄₀ = quadForm ![β₀,β₁] (−ρ) 1`, a unit precisely because the quadratic has no
residue root; Hensel gives `r ≡ ρ`, and the cofactor's residues are `ḡ₁ = β̄₁`, `ḡ₀ = β̄₀`, so
`Anisotropic (peel a r)` by `leanfinal`'s `Anisotropic_congr` and
`typeOf_inert_of_anisotropic` finishes.

**`{(1,1),(2,1)}`.** `f̄ = X²(X + ā₂)` with `ā₂ ≠ 0`. The residue root `ρ = −a₂` is simple:
`f̄′(−ā₂) = 3ā₂² − 2ā₂² = ā₂²`, a unit in every characteristic. Hensel gives a UNIT root `r`, the
cofactor has `ḡ₁ = ḡ₀ = 0`, and `a₀ = −r g₀` with `r` a unit transports `v(a₀) = 1` to
`v(g₀) = 1`: the cofactor is Eisenstein, `typeOf_ram_of_eisenstein` finishes.

**`{(1,1)}³`, level 1.** Three distinct residue roots `ρ̄₁,ρ̄₂,ρ̄₃`. Hensel at `ρ₁` (derivative
`(ρ₁−ρ₂)(ρ₁−ρ₃)`), peel, and the cofactor still has a simple residue root at `ρ̄₂` (derivative
`ρ̄₂ − ρ̄₃`); a second Hensel gives an actual root of the quadratic in `O` and
`typeOf_split_of_root` finishes. **Vacuous at `q = 2`** — no cubic over `𝔽₂` has three distinct
roots — which is why the split type also needs:

**`{(1,1)}³`, deep (level 3).** Every `a ≡ (0, π, −(1+π)) mod 𝔪³` splits. Residually
`f̄ = X²(X−1)`, so Hensel at `1` gives `r ≡ 1 (mod 𝔪)`. The bootstrap is the interesting step:
substituting `a₀ = π³u₀`, `a₁ = π + π³u₁`, `a₂ = −(1+π) + π³u₂` into `f(r) = 0` gives

    r (r − π) (r − 1) = π³ · (−(u₂r² + u₁r + u₀)) ,

and `r`, `r − π` are units (both `≡ 1 mod 𝔪`), so `π³ ∣ (r − 1)`: the Hensel root is pinned to
depth 3, not depth 1. Hence `g₁ = a₂ + r = −π + π³(…)` has EXACT valuation 1 while
`g₀ = −a₀/r` has valuation `≥ 3`, which is `leanfinal`'s `CertSplit` at the centre `0` with
`w = 1` (`v(F(0)) = 3 > 2 = 2w`), and `typeOf_of_certSplit` finishes.

**`{(3,1)}` and `{(1,3)}`** both need the cubic norm form, which is built in `N3Norm` by the same
route `QuadCert.lean` uses at degree 2: the power basis `(1, θ, θ²)` of `AdjoinRoot (cub3 b)`, the
explicit `3 × 3` multiplication matrix `cubMat b u`, and `Algebra.norm = det`.

* Eisenstein: `N(θ) = −a₀` has valuation exactly 1, so `1 ∈ normValues`, so `inertiaDegOf = 1`,
  `ramIndexOf = 3`, and irreducibility comes from Mathlib's `IsEisensteinAt.irreducible`.
* Residually irreducible: `3 ∈ normValues` is free (`natDegree_mem_normValues`), and
  `3 ∣ v(N(x))` for every `x ≠ 0` by strong induction on `v(N(x))`. The base case is the key
  lemma `isUnit_norm_of_unit_coeff`: because `cubMat` is a *polynomial expression in the
  coefficients*, `residue O (N(x)) = N_{k}(x̄)` (`residue_norm_cub`, one `RingHom.map_det`), and
  `k[x]/(f̄)` is a FIELD when `f̄` is irreducible, so a nonzero `x̄` has nonzero norm. The step
  case peels `π`: `N(πy) = π³N(y)`.

**From certificates to densities.** `genuineDensity_ge_of_inj` (N3Density) converts an
*injection* of a finite type into the σ-decided level-`N` classes into the bound
`#A / q^{3N} ≤ genuineDensity`; only an injection is needed, never an exact cardinality of the
decided set, which is what makes the family bounds cheap. Upper bounds come from
`leanfinal`'s `sum_genuineDensity_le_one`, **which is general in `n`** (checked: the `n = 2`-only
statement is `sum_three_densities_eq_one`, and it is NOT used here) — packaged as `bracket_five`.

## 3. EVERY NEW DEFINITION, WITH ITS FAITHFULNESS PARAGRAPH

Definitions are the trust boundary. None of these appears in the statement of a headline density
theorem — those mention only `leanfinal`'s `genuineDensity` and `residueCard` plus the five named
types — but the five types DO appear, so they head the list.

### `c3split`, `c3linInert`, `c3inert`, `c3linRam`, `c3ram` (`N3Base.lean`)

```lean
def c3split    : FactorizationType := ⟨{(1, 1), (1, 1), (1, 1)}⟩
def c3linInert : FactorizationType := ⟨{(1, 1), (1, 2)}⟩
def c3inert    : FactorizationType := ⟨{(1, 3)}⟩
def c3linRam   : FactorizationType := ⟨{(1, 1), (2, 1)}⟩
def c3ram      : FactorizationType := ⟨{(3, 1)}⟩
```

**Faithfulness.** `FactorizationType` wraps a multiset of `(e, f)` pairs and
`FactorizationType.degree σ = ∑ eᵢfᵢ`. `c3*_degree : … = 3` is proved by `decide` for all five, so
these are exactly the five degree-3 types with the standard `(ramification, residue degree)`
ordering that `leanfinal`'s `typeOf` produces (`efPair g = (ramIndexOf g, inertiaDegOf g)`).
Pairwise distinctness (`c3split_ne_c3linInert` and the other nine) is `decide` on the underlying
multisets — needed because `sum_genuineDensity_le_one` sums over a `Finset` of types and would be
vacuous if two coincided. ⚠ The ORDER convention is the one place a silent error could hide: if
`typeOf` returned `(f, e)` instead of `(e, f)`, `c3inert = ⟨{(1,3)}⟩` and `c3ram = ⟨{(3,1)}⟩` would
be swapped and every result here would still compile. The convention is fixed and checked by
`leanfinal`'s own `typeOf_ram_of_eisenstein : typeOf (Eisenstein quadratic) = ramType = ⟨{(2,1)}⟩`,
which this unit consumes for the `{(1,1),(2,1)}` type, and by `ramIndexOf_mul_inertiaDegOf`.

### `peel` (`N3Base.lean`)

```lean
def peel (a : Fin 3 → O) (r : O) : Fin 2 → O := ![a 1 + a 2 * r + r ^ 2, a 2 + r]
```

**Faithfulness.** The coefficient vector of the quadratic cofactor `f / (X − r)`. Junk unless
`r` is a root; the only property used is `cubic_peel`, which states
`monicPoly a = (X − C r) * monicPoly (peel a r)` UNDER the hypothesis `f(r) = 0` and is a `ring`
identity after substituting that hypothesis. No division and no `Polynomial.divByMonic` is
involved, so nothing can be lost when the hypothesis is absent.

### `cub3`, `cubBasis`, `cubElt`, `cubMat`, `resVec` (`N3Norm.lean`)

```lean
noncomputable def cub3 (b : Fin 3 → R) : Polynomial R := X ^ 3 + C (b 2) * X ^ 2 + C (b 1) * X + C (b 0)
noncomputable def cubElt (b u : Fin 3 → R) : AdjoinRoot (cub3 b) := algebraMap R _ (u 0) + algebraMap R _ (u 1) * θ + algebraMap R _ (u 2) * θ ^ 2
def cubMat (b u : Fin 3 → R) : Matrix (Fin 3) (Fin 3) R := !![ … ]     -- displayed in the file
noncomputable def resVec (a : Fin 3 → O) : Fin 3 → ResidueField O := fun i => residue O (a i)
```

**Faithfulness.** `cub3` is `monicPoly` at `n = 3` — `monicPoly_eq_cub3 : monicPoly a = cub3 a` is
proved (it is `cubic_expand`), so the two are interchangeable and no separate polynomial is
introduced. `cubBasis` is `(AdjoinRoot.powerBasis' (cub3_monic b)).basis` reindexed along
`cub3_natDegree`, i.e. literally `(1, θ, θ²)` (`cubBasis_zero/_one/_two` proved), the same
construction `QuadCert.quadBasis` uses at degree 2. `cubMat` is NOT assumed to be the
multiplication matrix: `leftMulMatrix_cub` PROVES that
`Algebra.leftMulMatrix (cubBasis b) (cubElt b u) = cubMat b u`, entry by entry, from the defining
relation `root_cube : θ³ = −b₂θ² − b₁θ − b₀`. Everything is stated over an arbitrary nontrivial
commutative ring, which is exactly what makes the reduction lemma
`cubMat_map : (cubMat a u).map (residue O) = cubMat (resVec a) (resVec u)` a one-line `simp`, and
hence `residue_norm_cub` a one-line `RingHom.map_det`.

### `NoRootCubic`, `linAniCoeff`, `LinAni` (`CubicCount.lean`)

```lean
def NoRootCubic {K} [Field K] (c : Fin 3 → K) : Prop := ∀ y : K, y ^ 3 + c 2 * y ^ 2 + c 1 * y + c 0 ≠ 0
def linAniCoeff {K} [Field K] (ρ : K) (p : K × K) : Fin 3 → K := ![-(ρ * p.1), p.1 + ρ * p.2, -(p.2 + ρ)]
def LinAni {K} [Field K] (c : Fin 3 → K) : Prop := ∃ (ρ : K) (p : K × K), AniK p ∧ c = linAniCoeff ρ p
```

**Faithfulness.** `NoRootCubic c` says the monic cubic with coefficient vector `c` has no root in
`K`; over a field a cubic is irreducible **iff** it has no root, and the direction used
(`no root ⟹ irreducible`) is Mathlib's `irreducible_of_degree_le_three_of_not_isRoot`, applied to
`cub3 c` after `cub3_eval` identifies the displayed polynomial expression with `eval`.
`linAniCoeff ρ (b₀,b₁)` is the coefficient vector of `(X − ρ)(X² − b₁X + b₀)` — expand and check.
`AniK (b₀,b₁)` (from the `n = 2` unit) says `y² − b₁y + b₀` has no root, so `LinAni` is exactly
"linear factor times irreducible quadratic". ⚠ **Sign bookkeeping is the live hazard here**:
`AniK` is keyed to `X² − b₁X + b₀` while `leanfinal`'s `Anisotropic ![β₀, β₁]` is keyed to
`monicPoly ![β₀,β₁] = X² + β₁X + β₀`, so the transport in `N3Gates.linInert_decided_res` passes
`β₁ = −b₁` and routes through the explicitly proved bridge `aniK_neg : AniK (x,y) → AniK (x,−y)`
(substitution `t ↦ −t`). The numeric check of §6 is what makes this bookkeeping non-circular:
`#LinAni = 2, 9, 50` at `q = 2, 3, 5` matches `q²(q−1)/2`.

### `unitSet` (`N3Density.lean`)

```lean
def unitSet (π : O) (N : ℕ) : Set (Res O N) := (dvdSet π 1 N)ᶜ
```

**Faithfulness.** The complement of the valuation-`≥ 1` stratum of `Res O N`, i.e. the units of
the truncation. Read downstairs; that this agrees with the upstairs reading is `dvd_res_iff` (the
`n = 2` unit's lemma), and its cardinality `q^N − q^{N−1}` is proved at `N = 2` by
complementation (`card_unitSet_two : #unitSet + q = q²`), not assumed.

### `res1Equiv`, `liftRes1` (`N3Gates.lean`)

```lean
noncomputable def res1Equiv (O) [ … ] : Res O 1 ≃+* ResidueField O := Ideal.quotEquivOfEq (pow_one (maximalIdeal O))
noncomputable def liftRes1 (v : Fin 3 → ResidueField O) : Coeff O 3 1 := fun i => (res1Equiv O).symm (v i)
```

**Faithfulness.** `Res O 1 = O ⧸ 𝔪¹` and `ResidueField O = O ⧸ 𝔪` are the same ring; `res1Equiv`
is the canonical identification and `res1Equiv_mk` (proved) says it commutes with the quotient
maps, which is the only property used. `liftRes1` is therefore a bijection onto the level-1
classes, and `resVec_of_proj` proves that every lift of `liftRes1 v` has residue vector exactly
`v` — the link between the residue-field counts and the level-1 decided classes.

## 7. `class_pinned` AT `n = 3` — THE FEASIBILITY VERDICT (reconnaissance)

**Verdict in one line: the pinning ARITHMETIC generalises cleanly and gives drainage, but a single
`class_pinned` analogue is FALSE at `n = 3`; two branches are needed, and the second branch is
blocked on a Hensel *coprime-factorisation* lemma that neither `leanfinal` nor (readily) Mathlib

**What `n = 2` does** (the precise statements, not a gesture: `Drainage.cert_of_not_tang`,
`Drainage.decidedAt_of_not_tang`, `Drainage.class_pinned`, `Drainage.undecidedCount_le`).
`decidedAt_of_not_tang` is the one that makes "one cause" precise: if NO centre `γ` satisfies
`Tang π a N γ` (`π^N ∣ F(γ)` and `π^{⌈N/2⌉} ∣ F'(γ)`) then the class IS decided; contrapositively,
every undecided level-`N` class has a centre of tangency depth `N`, which is the quantitative
hypothesis `class_pinned` consumes. `class_pinned` says: two data `(a, γ)`, `(a', γ')` with
tangency depth `2M` (`π^{2M} ∣ F(γ)`, `π^M ∣ F'(γ)`), with `γ ≡ γ' mod π^M` and
`a₁ ≡ a₁' mod π^{2M}`, have `a₀ ≡ a₀' mod π^{2M}`. So the undecided classes at level `2M` inject
into `(γ mod π^M) × (a₁ mod π^{2M})`, giving `undecidedCount ≤ q^{3M}` out of `q^{4M}`. The
mechanism is that `F(γ+δ) = F(γ) + F'(γ)δ + δ²` and BOTH error terms are killed by the tangency
hypothesis once `v(δ) ≥ M`. Its force comes from `cert_of_not_tang`: at `n = 2` "undecided" has
exactly ONE cause, a near-double root, and the certificate trichotomy is exhaustive.

**Branch (i) — the triple-tangency stratum: the arithmetic works.** At `n = 3` recentre
`f(X+γ) = X³ + B₂X² + B₁X + B₀` with `B₂ = 3γ + a₂`, `B₁ = 3γ² + 2a₂γ + a₁`, `B₀ = f(γ)`. On the
TRP stratum (`f̄ = (X − c̄)³`, HEX3 §S1's undecided locus) the natural depth-`N` tangency is
`v(B₀) ≥ N`, `v(B₁) ≥ ⌈2N/3⌉`, `v(B₂) ≥ ⌈N/3⌉` — the slope-`1/3` Newton condition. Taking
`δ = π^m s` with `m = ⌈N/3⌉`, the Taylor expansion
`B₀(γ+δ) = B₀ + B₁δ + B₂δ² + δ³` has all three error terms of valuation `≥ N`
(`2N/3 + N/3`, `N/3 + 2N/3`, `3·N/3`), so `(γ mod π^{⌈N/3⌉}, a₂ mod π^N, a₁ mod π^N)` pins
`a₀ mod π^N`. That is an injection into a set of size `q^{N/3} · q^{2N}` out of `q^{3N}`: a
saving of `q^{2N/3}`, enough for drainage. This branch is a direct, characteristic-free Taylor
computation and would formalise at roughly the length of `class_pinned` itself.

**Branch (ii) — why one branch does not suffice.** A cubic can be undecided while NO centre is
triply tangent. Take `f̄ = (X − ρ̄)(X − c̄)²` with `ρ̄ ≠ c̄`: at the centre `c` one has
`B̄₂ = 3c̄ + ā₂ = c̄ − ρ̄ ≠ 0`, so the depth-`N` tangency above fails at every centre, yet the class
is undecided exactly when the quadratic block `(X − c)²`-part is `n = 2`-undecided. This is
precisely HEX3's "β re-entry" family, and it is why HEX3's law
`u(q,N) = q^{2N−2} + (q−1)Σ_k q^{4k−1}(q^{N−3k}−1)R(N−3k)` carries the `n = 2` block laws `R(M)`
as factors. The pinning for this branch is: the Hensel root `r` of the separable linear factor is
determined by the class (`q^N` choices), and the quadratic cofactor is pinned by `n = 2`'s own
`class_pinned` (`q^{3N/2}`), total `q^{5N/2}` out of `q^{3N}` — also draining, at rate `q^{−N/2}`.

**The missing mechanism.** Branch (ii) needs, as a *theorem*, the statement "undecided at level
`N` and not triply tangent ⟹ `f` factors as (decided linear) × (quadratic), with the factorisation
determined by the class". That is Hensel's lemma in its FACTORISATION form — lift a coprime
residual factorisation `f̄ = ḡ · h̄` to `f = g · h` — which
* `leanfinal` does not have (it only has the ROOT form, `HenselianLocalRing.is_henselian`), and
* Mathlib does not obviously have for a general henselian local ring (grep found only the root
  form and `HenselianLocalRing.TFAE`).
This unit's certificates dodge the issue because they always have a *simple residue root* to
Hensel at, and then peel by the factor theorem; that dodge is unavailable for a general undecided
class, where the residual repeated factor may be the quadratic one.

**Recommendation for the eventual general-`n` drainage design.** Either
(a) prove the coprime-factorisation Hensel lemma once (it is the reusable object: at degree `n`
the induction "separable residual factor ⟹ split off and recurse" is the whole drainage
skeleton), or
(b) route drainage through the DISCRIMINANT instead: `{v(disc f) ≥ N}` is a hypersurface
neighbourhood whose measure is easy to bound (`disc` is quadratic in `a₀`, so each fibre
contributes `O(q^{−N/2})`), and the required implication "small `v(disc)` ⟹ decided" is a single
Krasner-type statement, independent of `n`. Route (b) trades one hard lemma for another but the
counting side becomes trivial and uniform in `n`; route (a) matches HMENU3/HEX3's own recursive
architecture and would be reusable by the menu side. **No evidence was gathered in this unit for
which is cheaper; that comparison is itself the next reconnaissance task.**

## 9. THE MATHEMATICS OF PART II (written before the Lean)

### 9.1 The residue trichotomy — the enumeration §7 asked for, re-derived and CORRECTED

**THEOREM (trichotomy).** Let `K` be a field and `F = X³ + c₂X² + c₁X + c₀ ∈ K[X]`. Exactly one
of the following holds:

* **(T1)** `F` has a SIMPLE root in `K`: some `ρ` with `F(ρ) = 0` and `F′(ρ) ≠ 0`;
* **(T2)** `F` has NO root in `K` (equivalently, `F` is irreducible over `K`);
* **(T3)** `F = (X − γ)³` for a (unique) `γ ∈ K`.

*Proof.* Suppose `F` has a root but no simple root, and let `ρ` be a root; then `F′(ρ) = 0`.
Peel: `F = (X − ρ)(X² + bX + d)` with `b = c₂ + ρ`, `d = c₁ + c₂ρ + ρ²` (this is `peel`).
Differentiating the product, `F′(ρ) = ρ² + bρ + d`, so the cofactor also vanishes at `ρ`, hence
`F = (X − ρ)²(X − s)` with `s = −c₂ − 2ρ`. Now `F(s) = 0` and `F′(s) = (s − ρ)²`. If `s ≠ ρ`
then `s` is a simple root — contradiction. So `s = ρ`, i.e. `c₂ = −3ρ`, and then `c₁ = 3ρ²`,
`c₀ = −ρ³`, i.e. `F = (X − ρ)³`. Uniqueness of `γ`: from `3γ = 3γ′`, `3γ² = 3γ′²`, `γ³ = γ′³`
one gets `(γ − γ′)³ = γ³ − 3γ²γ′ + 3γγ′² − γ′³ = γ³ − 3γ′³ + 3γ′³ − γ′³ = 0`. ∎

Everything is a `ring` identity; **no characteristic hypothesis is used**, so the wild primes
`2` and `3` are covered (in characteristic `3`, (T3) reads `F = X³ − γ³` with `c₂ = c₁ = 0`).

**Consequence — the Hensel note's retraction is CONFIRMED, in a stronger form.** `N3_CHECK` §7
diagnosed branch (ii) as blocked on a coprime-factorisation Hensel lemma. It is not: by (T1)–(T3)
the only residual shapes WITHOUT a simple root are "irreducible" and `(X − γ̄)³`, and the first is
already decided at level 1 by `typeOf_inert3_of_residue_irreducible`. So every undecided class
that is not residually a perfect cube has a SIMPLE residual root, and the ROOT form of Hensel
peels it. **No third genre exists.** Two refinements of the Hensel note's phrasing:

* the note said the only undecided-not-triply-tangent genre is `(X − ρ̄)(X − c̄)²`. That is true
  but it is *not* a consequence of the enumeration alone: the shapes "three distinct roots" and
  "linear × irreducible quadratic" also have simple roots and are excluded only because this
  repo's own level-1 certificates DECIDE them. The enumeration-only statement is the weaker and
  cleaner "has a simple residual root".
* the peel below therefore does not need the `(X − ρ̄)(X − c̄)²` shape at all: one theorem covers
  all three simple-root shapes.

### 9.2 Branch (b): the peel reduces `n = 3` decidedness to `n = 2` decidedness, LOSSLESSLY

Write `F_a = monicPoly a = X³ + a₂X² + a₁X + a₀`, and `g = peel a r = ![a₁ + a₂r + r², a₂ + r]`
for the quadratic cofactor at a root `r` (`cubic_peel`: `F_a = (X − r)·monicPoly g`, a `ring`
identity).

**LEMMA B (branch-(b) decidedness).** Let `N ≥ 1`, let `r ∈ O` satisfy `F_a(r) = 0` with
`F_a′(r)` a UNIT, and suppose the quadratic cofactor `g = peel a r` has NO centre of tangency
depth `N` (`¬ ∃ γ, Tang π g N γ`). Then the level-`N` class of `a` is decided, with type
`{(1,1)} ∪ typeOf (monicPoly g)`.

*Proof.* Let `a′` be any lift of the same class, so `π^N ∣ a′ᵢ − aᵢ` for each `i`.

1. `E := F_{a′}(r) = F_a(r) + Σᵢ (a′ᵢ − aᵢ)rⁱ ∈ π^N O`.
2. `F_{a′}′(r) − F_a′(r) = 2(a′₂ − a₂)r + (a′₁ − a₁) ∈ 𝔪` (here `N ≥ 1` is used), so
   `F_{a′}′(r)` is a unit too.
3. Ordinary Hensel at `r` (mathlib's root form, via `exists_cubic_root`) gives `r′` with
   `F_{a′}(r′) = 0` and `δ := r′ − r ∈ 𝔪`.
4. **The quantitative step, and it is elementary.** Expanding the cubic exactly,
   `0 = F_{a′}(r + δ) = E + δ·(F_{a′}′(r) + (3r + a′₂)δ + δ²)`. The bracket is a unit + `𝔪`,
   hence a unit; so `δ·(unit) = −E ∈ π^N O`, whence `π^N ∣ δ`. **No digits are lost.**
   *(This is the finite-level class-determinacy that `HENSEL_FACT` §7 item 2 asked for, in the
   only case branch (b) needs. It does not require re-running the Newton iteration, because the
   derivative is a unit: the correction is first-order exactly.)*
5. Hence `peel a′ r′ ≡ peel a r (mod π^N)` coefficientwise (`peel` is a polynomial in `a` and `r`).
6. `leanfinal`'s `decidedAt_of_not_tang` says the level-`N` class of `g` is
   `typeOf (monicPoly g)`-decided; by 5, `typeOf (monicPoly (peel a′ r′)) = typeOf (monicPoly g)`.
7. `typeOf` is additive on monic products (`typeOf_mul`), so
   `typeOf F_{a′} = (1,1) ::ₘ typeOf (monicPoly (peel a′ r′)) = (1,1) ::ₘ typeOf (monicPoly g)
   = typeOf F_a`. ∎

### 9.3 The count: undecided ⊆ peel-tangent ∪ triple-root, and the two bounds

**STRUCTURE (drainage dichotomy).** For `N ≥ 1`,

    undecidedSet O 3 N  ⊆  peelSet π N  ∪  tripleSet π N

where `peelSet π N = {c | some lift a of c has a root r with Tang π (peel a r) N γ for some γ}`
and `tripleSet π N = {c | some lift a of c is residually (X − γ)³ for some γ}`. *Proof.* Apply
the trichotomy to the residue of a lift `a`. (T2) ⟹ decided at level 1, hence at level `N`,
contradicting undecidedness. (T1) ⟹ Hensel gives `r` with `F_a(r) = 0` and unit derivative; if
`peel a r` had no tangent centre, Lemma B would decide the class — so it has one, i.e.
`c ∈ peelSet`. (T3) ⟹ `c ∈ tripleSet`. ∎

**BOUND 1 (branch b).** `#(peelSet π (2M)) ≤ q^{5M}`, out of `q^{6M}` classes.
*Proof.* A cubic with a root `r` and cofactor `g` has `a = ![−r g₀, g₀ − g₁ r, g₁ − r]`, so the
class is a function of `(r, g₀, g₁) mod π^{2M}`. Map `c ↦ (r mod π^{2M}, γ mod π^M, c₂)`, where
`γ` is a tangency centre of depth `2M` for `g`. If two classes have the same image then
`g₁ = a₂ + r` agrees mod `π^{2M}`, and `leanfinal`'s `class_pinned` (exported completeness-free
as `class_pinned'` in `DeepSet.lean`) forces `g₀` to agree mod `π^{2M}` — so the classes are
equal. The target has `q^{2M}·q^M·q^{2M} = q^{5M}` elements. ∎

**BOUND 2 (triple-root stratum).** `#(tripleSet π N) ≤ q^{3N−2}` for `N ≥ 1`: the level-1
truncation of such a class is `(X − γ̄)³`, and `γ̄` is unique, so at most `q` of the `q³` level-1
classes are hit; each has `q^{3(N−1)}` refinements.

Hence `undecidedSeq O 3 (2M) ≤ q^{−M} + q^{−2}`, and therefore for every `σ`

    upperDensity O 3 σ  ≤  genuineDensity O 3 σ  +  1/q²  ,

i.e. **the `n = 3` bracket between the certified (decided) density and the possible density
closes to within `1/q²`** — `1/4` at `q = 2`, `1/9` at `q = 3`. Full drainage is exactly the
statement that the *triple-root* part of the undecided set drains; branch (b) is finished.

### 9.4 What full `n = 3` drainage still needs (the honest gap, diagnosed)

On the triple-root stratum, recentre at a lift `c` of `γ̄`: `F(X + c) = X³ + B₂X² + B₁X + B₀`
with all `Bᵢ ∈ 𝔪`. Reading the Newton polygon of `(B₀, B₁, B₂, 1)`:

| polygon | verdict | tool status |
|---|---|---|
| `v(B₀) = 1` | Eisenstein, `{(3,1)}` | HAVE (`typeOf_ram3_of_eisenstein`) — but needs typeOf SHIFT-invariance to use at `c ≠ 0` |
| `v(B₀) = t ≢ 0 (3)`, single side | `e = 3`, `{(3,1)}` | provable by the same norm route (`CertRam3`, not landed) |
| single side of INTEGRAL slope `m` | rescale `X = π^m Y`, recurse on the residual cubic | needs typeOf SCALE-invariance |
| **two or three sides** | a root of `F` in `O` whose derivative is NOT a unit | **BLOCKED: needs STRONG HENSEL** |

**The blocking tool is strong Hensel, not the factorization form.** Precisely: `F` monic with
`v(F(x₀)) > 2·v(F′(x₀)) = 2w`, `w ≥ 1` ⟹ `∃ r, F(r) = 0 ∧ v(r − x₀) > w`. Two observations
recorded for the next unit:

* mathlib has this only for `ℤ_[p]` (`hensels_lemma` in `NumberTheory/Padics/Hensel.lean`), not
  for a general complete DVR; `HenselianLocalRing.is_henselian` is the `w = 0` case only.
* **`Uniformity.Hensel.exists_monic_factorization` does NOT supply it.** After recentring, the
  residual factorization is `X · X²`, which is not coprime; and the scalings that separate the
  polygon sides are non-integral, so no monic model exists to feed the factorization form. The
  factorization form remains the right tool for `n ≥ 4` (two repeated residual blocks), as its
  own note says — it is simply not what the `n = 3` triple-root branch is short of.
* degree 2 escapes this because `F(γ + π^w y)/π^{2w}` is monic when `deg F = 2`
  (`typeOf_of_certSplit`'s trick); at degree 3 the same division leaves leading coefficient
  `π^w`, i.e. a NON-MONIC polynomial with a simple residual root — the general statement mathlib
  also lacks. Strong Hensel and non-monic Hensel are the same missing lemma.

Once strong Hensel exists, the triple-root branch closes by the recursion
`u(N) ≤ q^{−N/2} + q^{−5}·u(N − 3)` (each round consumes three digits of level and pins the
centre), which gives drainage; that estimate is written out here so the next unit can check it
against its own bookkeeping, but it is NOT proved.
