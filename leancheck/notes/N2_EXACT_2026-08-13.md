### How `split = inert` was obtained (it is NOT an involution)

The note's §3B.3 warned that at residue characteristic 2 there is no uniform coefficient
bijection swapping split and inert. This unit **avoids the symmetry argument entirely**: it
computes `ram` and `inert` exactly by census, and gets `split` by subtraction from the landed
`Uniformity.Density.sum_three_densities_eq_one` (split + inert + ram = 1). The symmetry is then a
corollary of two independent exact evaluations. The characteristic-uniformity that W-11 observed
at the branching level survives as the single uniform constant
`A = #{anisotropic residue pairs} = q(q-1)/2` — one count, both characteristics.

## 2. THE MATHEMATICS (written before the Lean)

Fix a uniformizer `π`, degree 2, level `N`, and write `F(γ) = γ² + a₁γ + a₀`, `F'(γ) = 2γ + a₁`
(`qval`, `qder` of `Drainage.lean`). `Drainage.lean` already provides the trichotomy: if no centre
reaches tangency depth `N`, the class carries exactly one of `CertSplit`, `CertRam`, `CertInert`,
and each certificate determines the type. What was missing was the **counting**.

**The census lemma** (`Counting.card_certSet`). Let `cert γ c` be a certificate at a centre for
level-`N` classes such that (i) it reads only the pair `(F(γ), F'(γ))`, through an admissible set
`S`; (ii) it survives every move of the centre inside `γ + 𝔪^m`; (iii) it forces all its centres
into one such coset. Then

    #{certified classes} = q^m · #S.

The engine is `readEquiv γ : Coeff O 2 N ≃ Res O N × Res O N`, `c ↦ (F(γ), F'(γ))` — a bijection
for each fixed centre — plus a set-theoretic section of `Res O N → Res O m`.

**RAM.** `RamAt π j a γ`: `v(F(γ)) = 2j+1` exactly, `v(F'(γ)) ≥ j+1`. Recentring by `δ`:
`F(γ+δ) = F(γ) + F'(γ)δ + δ²`.
*Shift* (`RamAt_shift`): `v(δ) ≥ j+1` moves `F(γ)` by something of valuation `≥ 2j+2`, so the odd
exact valuation `2j+1` survives.
*Uniqueness* (`RamAt_uniq`): `v(δ) = m ≤ j` makes `v(F(γ+δ)) = 2m`, EVEN — no odd certificate
there. So the centre is pinned mod `𝔪^(j+1)` and `j` is determined by the class. Hence with
`S = {v(V) = 2j+1 exactly} × {v(D) ≥ j+1}`,

    #RAM(j) at level N = 2j+2+r  =  q^(j+1) · (q-1)q^r · q^(j+1+r)  =  (q-1) q^(2j+2r+2).

**INERT.** `InertAt π k a γ`: `F(γ) = π^(2k) b₀`, `F'(γ) = π^k b₁`, `![b₀,b₁]` anisotropic.
*Shift* (`InertAt_shift`, at scale `k`, not `k+1`): recentring by `δ = π^k z` sends the residual
form by the unimodular substitution `quadForm ![b₀',b₁'] u v = quadForm ![b₀,b₁] (u - zv) v`, so
anisotropy is preserved.
*Uniqueness* (`InertAt_uniq`): `v(δ) = m < k` gives `v(F(γ+δ)) = 2m` with residual form having
the zero `(δ/π^m, 1)` — isotropic, so no certificate there. Centre pinned mod `𝔪^k`, `k`
determined. With `A = #{(b̄₀,b̄₁) : y² - b̄₁y + b̄₀ irreducible} = q(q-1)/2`,

    #INERT(k) at level N = 2k+1+r  =  q^k · A q^r · q^(k+r)  =  A q^(2k+2r).

**Summation.** At `N = 2M` the parameters run `j, k < M`, and reflecting the index (`j = M-1-i`)
turns both families into `c · q^(2M+2i)` with `c = q-1` resp. `c = A`. The geometric sum gives
`c(q^(4M) - q^(2M))/(q²-1)`, i.e. normalised `(c/(q²-1))(1 - q^(-2M))`.

**Closing the bracket.** A decided class of type σ either carries the matching certificate or is
deeply tangent (`decided_ram_subset`, `decided_inert_subset`, via `cert_of_not_tang` plus the
type distinctions `splitType ≠ ramType` etc.), and the deep classes number at most `q^(3M)`
(`DeepSet.card_deepSet_le`, the pinning half of `undecidedCount_le`). So

    census ≤ decidedCount(2M) ≤ census + q^(3M),

and dividing by `q^(4M)` the slack `q^(-M)` drains: `genuineDensity O 2 σ = c/(q²-1)`
(`N2Base.genuineDensity_of_census`). At `c = q-1` that is `1/(q+1)`; at `c = A = (q²-q)/2` it is
`q/(2(q+1))`.

## 3. EVERY NEW DEFINITION, WITH ITS FAITHFULNESS PARAGRAPH

Definitions are the trust boundary. None of these appears in the statement of a headline theorem
— the headline statements mention only `leanfinal`'s `genuineDensity`, `residueCard`, and the
named types — but they are new definitions, so each is flagged for review.

### `resPi`, `dvdSet`, `exactSet` (`Counting.lean`)

```lean
def resPi (π : O) (N : ℕ) : Res O N := Ideal.Quotient.mk _ π
def dvdSet (π : O) (k N : ℕ) : Set (Res O N) := {x | resPi π N ^ k ∣ x}
def exactSet (π : O) (k N : ℕ) : Set (Res O N) :=
  {x | resPi π N ^ k ∣ x ∧ ¬ resPi π N ^ (k + 1) ∣ x}
```

**Faithfulness.** `dvdSet π k N` is the valuation-`≥ k` stratum of the truncation and `exactSet`
the valuation-exactly-`k` one, *read downstairs*. That this agrees with the upstairs reading is
`dvd_res_iff` (proved): for `k ≤ N`, `π̄^k ∣ [x] ↔ π^k ∣ x`. Outside the window the notion
degenerates (`π̄^N = 0`), which is why `exactSet π k N` is empty for `k ≥ N` — a fact the ram
census uses rather than hides. Cardinalities are proved, not assumed: `card_dvdSet` reads
`#dvdSet π k (k+r) = q^r` off the kernel of `Res O (k+r) → Res O k` via `LocalData`'s fibre
count.

### `readEquiv` (`Counting.lean`)

```lean
def readEquiv (γ : Res O N) : Coeff O 2 N ≃ Res O N × Res O N where
  toFun c := (c 0 + c 1 * γ + γ ^ 2, c 1 + 2 * γ)
  invFun p := ![p.1 + γ ^ 2 - p.2 * γ, p.2 - 2 * γ]
```

**Faithfulness.** For a lift `a` of the class and a lift `γ₀` of the centre, `readEquiv` returns
exactly `(F(γ₀) mod 𝔪^N, F'(γ₀) mod 𝔪^N)` — this is `readEquiv_proj`, proved, and it is the only
property used. It is an `Equiv` by construction (both round trips are `ring` identities), so no
counting is lost or gained; the inverse is the affine recovery `a₁ = D - 2γ`, `a₀ = V + γ² - Dγ`.
Nothing here assumes `2` invertible.

### `RamAt` / `RamCert` / `ramSet` (`RamCensus.lean`)

```lean
def RamAt (π : O) (j : ℕ) (a : Fin 2 → O) (γ : O) : Prop :=
  π ^ (2*j+1) ∣ qval a γ ∧ ¬ π ^ (2*j+2) ∣ qval a γ ∧ π ^ (j+1) ∣ qder a γ
def RamCert (π : O) (j N : ℕ) (γ : Res O N) (c : Coeff O 2 N) : Prop :=
  readEquiv γ c ∈ (exactSet π (2*j+1) N) ×ˢ (dvdSet π (j+1) N)
def ramSet (π : O) (j N : ℕ) : Set (Coeff O 2 N) := {c | ∃ γ, RamCert π j N γ c}
```

**Faithfulness.** `RamAt π j a γ` is `Drainage.CertRam`'s body with the existential over `(γ, j)`
stripped: `CertRam π a N ↔ ∃ γ j, 2j+2 ≤ N ∧ RamAt π j a γ` holds by definitional shuffling, and
the direction actually used is proved as `ramCert_iff` (downstairs ↔ upstairs, inside the
window) — so `ramSet` is a subset of the classes `Drainage` already certifies as ramified, and
`ramSet_subset_decided` routes it through `leanfinal`'s own `typeOf_of_certRam`. The parameter is
not an extra choice: `ramSet_param_unique` proves `j` is determined by the class.

### `InertAt` / `InertCert` / `inertSet` (`InertShift.lean`, `InertCensus.lean`)

```lean
def InertAt (π : O) (k : ℕ) (a : Fin 2 → O) (γ : O) : Prop :=
  ∃ b₀ b₁ : O, qval a γ = π ^ (2*k) * b₀ ∧ qder a γ = π ^ k * b₁ ∧ Anisotropic ![b₀, b₁]
def InertCert (π : O) (k N : ℕ) (γ : Res O N) (c : Coeff O 2 N) : Prop :=
  2 * k + 1 ≤ N ∧ readEquiv γ c ∈ aniPairSet π k N
def inertSet (π : O) (k N : ℕ) : Set (Coeff O 2 N) := {c | ∃ γ, InertCert π k N γ c}
```

**Faithfulness.** `InertAt` is `Drainage.CertInert`'s body with `(γ, k)` stripped, using
`leanfinal`'s own `Anisotropic`. ⚠ **The window condition `2k+1 ≤ N` is part of the CLASS-level
certificate on purpose**, and this is the one place where the downstairs reading is *not*
automatically faithful: with `π̄^(2k) = 0` for `2k ≥ N`, the degenerate pair `(0,0)` satisfies the
residual condition vacuously, so without the guard `inertSet π k N` would be nonempty for
arbitrarily large `k` and the family would not be summable. With the guard, `inertSet` is empty
outside the window (`inertSet_eq_empty`) and `inertCert_iff` proves it equivalent to `InertAt`
upstairs inside the window. (The ram family needs no such guard: `exactSet` is empty past the
window by itself.)

### `aniPairSet`, `AniK` (`AniCount.lean`, `FiniteFieldQuad.lean`)

```lean
def AniK {K : Type*} [Field K] (p : K × K) : Prop := ∀ y : K, y ^ 2 - p.2 * y + p.1 ≠ 0
def aniPairSet (π : O) (k N : ℕ) : Set (Res O N × Res O N) :=
  {p | ∃ b₀ b₁ : O, p.1 = resPi π N ^ (2*k) * (Ideal.Quotient.mk _ b₀) ∧
        p.2 = resPi π N ^ k * (Ideal.Quotient.mk _ b₁) ∧ Anisotropic ![b₀, b₁]}
```

**Faithfulness.** `AniK (b₀,b₁)` says the monic quadratic `y² - b₁y + b₀` has no root in the
field — equivalently (proved: `aniK_iff`) that the binary form `u² - b₁uv + b₀v²` has only the
trivial zero, which is `leanfinal`'s `Anisotropic` read over the residue field
(`anisotropic_iff_aniK`). `aniPairSet` is the admissible `(value, derivative)` set of the inert
certificate; its cardinality is `A q^(N-2k-1) q^(N-k-1)` with `2A + q = q²`, i.e.
`A = q(q-1)/2` — the number of monic irreducible quadratics over the residue field, obtained from
`#Sym2 K = C(q+1,2)` by complementation, **with no case split on the characteristic**.

### `deepSet`, `class_pinned'` (`DeepSet.lean`)

```lean
def deepSet (π : O) (N : ℕ) : Set (Coeff O 2 N) :=
  {c | ∃ a : Fin 2 → O, proj O 2 N a = c ∧ ∃ γ : O, Tang π a N γ}
```

**Faithfulness.** The classes with a centre of tangency depth `N` — the complement of the region
where `Drainage`'s dichotomy applies. `deep_of_mem_deepSet` proves it is a property of the class,
not of the lift. `class_pinned'` is a **verbatim re-proof** of `Uniformity.Density.class_pinned`
(documented as such at the declaration site): the original is auto-assigned
`[IsAdicComplete …]` by its section's `variable` block although its proof never uses it, and the
`deepSet` bound is deliberately completeness-free. If `leanfinal` is ever touched again, an
`omit [IsAdicComplete …] in` on `class_pinned` would remove the need for the copy.

## 8. WHAT `n = 3` SHOULD INHERIT

1. **The census lemma is degree-agnostic in form but degree-2 in content.**
   `Counting.card_certSet` is stated for `Coeff O 2 N` only because `readEquiv` is the *binary*
   recentring bijection. The generalisation to be written first is: for degree `n`, recentring at
   `γ` is still a bijection of the box (`c ↦ (F(γ), F'(γ), …, F^(n-1)(γ)/(n-1)!)` needs care in
   small characteristic — use the coefficients of `f(X+γ)` instead of derivatives, which is
   characteristic-free and still an affine bijection). With that, the "centre pinned mod `𝔪^m`"
   pattern transfers verbatim.
2. **The two centre lemmas are the whole game.** For each certificate family, the only inputs the
   census needs are *shift* (survives inside a coset) and *uniqueness* (fails outside it). At
   `n = 2` both come from one identity, `F(γ+δ) = F(γ) + F'(γ)δ + δ²`. At `n = 3` the analogue is
   the Taylor expansion of the recentred cubic, and the families are keyed by the Newton polygon
   of the recentred polynomial — expect three or four families per type instead of one.
3. **Do NOT plan on a symmetry argument.** The split/inert symmetry at `n = 2` was obtained by
   evaluating both sides, not by an involution; at `n = 3` the analogous coincidences (e.g. the
   two `(1,1)+(1,2)` vs `(1,3)` families) should likewise be *computed*, not matched.
4. **The residue-field input generalises to a counting problem, not a structure theorem.** All
   that `n = 2` needed was `#{irreducible monic quadratics} = q(q-1)/2`, and it was obtained by
   complementation from `#Sym2 K`. At `n = 3` the corresponding input is
   `#{irreducible monic cubics} = (q³-q)/3`, and the same complementation route
   (`Sym3`/multiset counting minus the reducible strata) avoids any characteristic case split.
   Get that count landed EARLY — it is the one piece with no `n = 2` precedent.
5. **The deep/undecided slack is reusable as-is in shape**: `decided ⊆ certified ∪ deep`,
   `#deep = o(q^(nN))`. At `n = 3` the pinning argument needs the analogue of `class_pinned`
   (which `leanfinal` has only at `n = 2`); that is the first thing to check for feasibility,
   because the whole "bracket closes" step depends on it.
