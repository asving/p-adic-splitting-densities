# Phase-C numerics regression — full falsifier/verification re-run (ID: REG)

**What this is.** The Phase-C regression leg of the open-math campaign: a clean re-run
of every standing numeric falsifier/verification suite at repo HEAD, checking that no
suite's verdict or numeric output has drifted from its last-known-good run. All suites
are CPU-only exact-arithmetic Python harnesses; a "PASS" means the suite's own internal
gates (preregistered predictions, sealed catalogues, violation counters) all report
green, and "no drift" means today's output is line-for-line identical to the cited
last-known-good log (timestamps/progress lines excluded).

## Environment notes

1. **sympy availability.** The box's system `python3` (3.10.12) has no sympy, so the
   five sympy-dependent suites were run with the sibling-project venv interpreter
   `/data/users/asvin/comp_icl/.venv/bin/python` (sympy 1.13.1). First attempts of
   `N6-regp_scan_ext2000`, `o11_seriestie_check` (its V1/V2 legs), and
   `o11_v2_oracle_pin` under system python3 failed with `ModuleNotFoundError: sympy`
   and were immediately re-run under the venv; only the venv runs are logged and
   scored. Nothing else on the box provides sympy — a future session may want a
   repo-local venv (`verification/README.md` already says `pip install sympy`).
2. **reconcile_om_bcfg runtime.** 472s wall, dominated by the exact OM n=6 table
   (~379s of it, then a silent ~79s sympy moment-comparison phase); the longest
   single suite after U6.
3. **U6 at full configs.** Run at the standing full rows (N=9/7/7/5), ~10 min wall,
   matching the 2026-07-31 10:05 baseline run row-for-row; `--quick` was not needed.
4. **o9_order2_census `fast`.** The `fast` flag drops the two ≥10^6-box restricted
   configs (p=5 n=3 M=5 restr(3,2,1); p=3 n=4 M=6 restr(4,3,2,1)). Those two are
   covered by the prior full run (`logs/o9_census_20260731_165908.log`, same day,
   GATE SURVIVES with 0 violations including both), which remains their LKG.
5. **Tracked-file hygiene.** Suites 2, 3, 11, 15, 17 rewrite tracked results JSONs; all
   regenerated byte-identical except `U6_krun_results.json`'s embedded run-date
   string, which was restored (`git checkout --`) to keep the shared tree clean. The
   working tree under `verification/` is git-clean after the run (one unrelated
   untracked file, `openmath/o9_rev4_fulladm_check.py`, belongs to a concurrent
   session and was not touched).
6. **Budget.** Total wall ≈ 20 minutes (long suites parallelized), inside the ~40 min
   cap; nothing was skipped, so no SKIPPED-cited rows.
