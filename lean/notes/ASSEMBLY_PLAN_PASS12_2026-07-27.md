## B. The ns route

The route is substantially improved:

- TGT explicitly splits \(\mathcal T^{\rm fin}\sqcup\mathcal T^{ns}\) and drops the latter only under `(ns-null)`.
- TREE-EXP-fin alone gets the ordinary node product.
- TREE-EXP-ns uses capped lumps and a displayed limit.
- (†-AGG)(vii) ranges only over \(\mathcal T^{\rm fin}\).
- SQ.1 puts ns fibers in \(\operatorname{Undec}(N)\).
- RS.1-SH locally retains the `(ns-null)` qualifier.

Two sites nevertheless remain ill-typed.

First, TREE-N writes

\[
\#\{f\bmod p^N:T_{\rm can}^{\tau}(f)=T\}
\]

for \(T\in\mathcal T^{ns}\). An exact ns condition is not determined modulo \(p^N\), so that set of residue classes is not defined without choosing saturation, containment, or another finite-level interpretation. The right side correctly invokes the lump \(L_{M(N)}\), but the left side still names the exact fiber. This is precisely an exact-ns object being treated as a finite-level cell.

Second, \(b_e^{ns}\) is defined as the entire eventual reachable-ns probability and then inserted additively into the exit vector, while the text also says every finite ns shadow remains inside the continuing vanishing-digit columns of \(K_e\). A tail event already propagated through those continuing columns is not a one-step exit. If it had positive mass, the equation

\[
\beta_e=K_e\beta_e+b_e
\]

would count the same ns paths through \(K_e\beta_e\) and through \(b_e^{ns}\). Under `(ns-null)` the term is zero, so the conditional final density is unaffected; nevertheless the displayed unconditional symbolic decomposition is false as typed.

Thus `(NS-ROUTE)` is not yet consistent at all citation sites.

The plan is honest elsewhere about this epistemic limitation, but CL-10 does not give `(ns-null)` an equally explicit derivation-only refutation channel.

## E. Fresh sweep

The ordinary first-split recursion still survives. The shared branching-cell mass is charged once, sibling continuations are member-indexed, and no unjustified multinomial remains.

Three lesser issues remain:

- The statement that \(\mathcal T^{ns}\) is countable needs a short indexing justification. A finite symbolic pro-leaf class would make this true; arbitrary exact infinite value-trees would not.
- TREE-EXP-ns writes \(\mu(L_{M(N)}\text{-block})\) in a product after the prefix factors. This must denote conditional block mass in the leaf frame. If it denotes unconditional cylinder mass, the shared prefix is charged twice.
- The label \([3t]\)-FULL can obscure that `(ns-null)` and other CL-10 kernels may remain open. The acceptance record rule prevents an actual false unconditional acceptance, but the name should not be read as global closure.
