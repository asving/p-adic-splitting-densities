## A. Critical errors

### 1. The semilinear pieces are not required to be disjoint, but INIT-RAT sums them as if they were

V.0 defines

> “`SEMILINEAR := a finite union of linear sets`”

with no disjointness requirement. V.3(iii) then derives INIT-RAT using

> “`ι_{e,(s,α)} = Σ_ε Σ_{c ⊆ H(ε)} I^ent_c(q) · Σ_{h_ent ∈ c}
> p^{−A(ε,h_ent)}`”

where \(c\) ranges over the listed linear sets.

That formula double-counts every point lying in two listed sets. For example,
in one height coordinate,

\[
L_0=L(0;\{1\})=\mathbf N,\qquad
L_1=L(1;\{1\})=\{1,2,\ldots\}
\]

are valid listed linear sets and \(L_0\cup L_1=\mathbf N\), but
\(\sum_{h\in L_0}w(h)+\sum_{h\in L_1}w(h)\) is not
\(\sum_{h\in\mathbf N}w(h)\).

The same issue affects the claimed rationality of
\(G=\sum_{h\in H(\gamma^1)}g(h)\): `(XHD-s)` supplies a rational sum
“per listed linear set,” not for their union after overlap correction.
Finite inclusion-exclusion is not available from the displayed hypothesis,
because intersections need not be among the explicitly listed sets to which
`(XHD-s)` applies.

Thus INIT-RAT and the one-step \(G\)-rationality do not follow from the exact
hypothesis set in the ledger. The package must require an explicitly listed
**disjoint** semilinear decomposition, or state `(XHD-s)` directly for the
set-union \(H(\gamma)\) and all overlap terms used in a displayed
inclusion-exclusion/disjointization.

### 2. `(iv)-MEAS` reintroduces ordinary-source disjointness forbidden by D4-R

V.1(iv) states:

> “`every (m, o, β, height-class) summand is identified with a measurable
> DISJOINT sub-event of the source cylinder`”

and V.3(iv) repeats:

> “`each (m, o, β, height-class) summand is the fiber of a finite-level map
> on the source cylinder`”.

This is false for the branch-indexed outcomes the note otherwise adopts.
D4-R L5 and its displayed F1 instance allow one digit cell to carry two
eligible \((\mathrm{side},\psi)\) continuations; the corresponding
next-node strata can be literally equal as subsets of the source cylinder.
PART-2 was introduced precisely because the continuation-indexed source
sets do not partition.

The summands can be made disjoint only after adjoining the continuation mark:
they are measurable subsets of the **marked** source space
\(\{(f,\eta)\}\), with the branch label included in the finite-level map.
Alternatively, only the digit cells may be called disjoint ordinary source
events, followed by a finite branch-set multiplicity. As written,
`(iv)-MEAS` contradicts the accepted D4-R interface and cannot be one of
RS.PRE's measured inputs.

### 3. Theorem VAL(b) claims an XHD-free path product whose required count lumpability is assumed in `(XHD-u)`

Theorem VAL(b) says:

> “`the PER-REPRESENTATIVE linked count from one fixed source representative
> is the PATH PRODUCT C_γ(q) = ∏_i T... — a DEFINED matrix operation by
> clause (i)'s one global partition`”.

A global partition makes the matrix indices type-check; it does not prove
that the number of next extensions is the same for every concrete target
representative inside a target cell. Without that equality, summing the
first-step landings and multiplying by one table value for the next cell is
invalid.

The note itself locates the missing assertion in `(XHD-u)`:

> “`(u-R) ... the ... count T_γ(x,h) depend[s] on x and its history ONLY
> through (α, β⃗, m⃗, o⃗, h)`”

and, more strongly,

> “`(u-T) ... T_γ(x,h) = ∏_i T...`”.

Consequently the count shadow in COMP-h is correctly ledgered GIVEN
`(XHD-u)`, but Theorem VAL(b), the full-count formula
\(\widehat C_{\epsilon,\gamma}=I^{ent}\prod T\), and their `(†)` use are
still presented as the XHD-free “count layer.” Calling the product a
defined matrix operation does not identify it with the actual linked count.
Either VAL(b) must be tagged GIVEN the count-lumpability face of `(XHD-u)`,
or the table-build deliverable must separately prove representative-uniform
count rows and the theorem/ledger must cite that proof. The current
XHD-free status is false.

## B. Justification gaps

### 4. PART-1's proof treats an all-height p-adic decomposition as a finite fresh pool

V.3(iv) argues:

> “`from one representative the fresh pool is finite and its DIGIT-CELL
> datum is a total single-valued function of the fresh assignment`”

and concludes that summing over

> “`all shapes, heights, values, terminal cells included`”

has mass \(1\).

At a fixed height the value-assignment pool is finite. Across all possible
valuations/heights, however, the source cylinder is an infinite p-adic
product and the decomposition is generally countable; total-window
degeneracy/no-finite-height behavior also needs explicit treatment. The
conclusion is plausibly recoverable from D4R.0 digit-cell totality,
countable additivity, `(XHD-d)` exactness, and `(XHD-s)` convergence (with
the semilinear repair above), but it is not a finite-pool consequence of
C.1.5(1). The proof route and clause ledger must name the countable
partition/null remainder argument actually used.

V.4 specifies step 2 only as

No step-2 species \(m_2\), outcome \(o_2\), target cell, source

The probe remains a coherent exploration design, but rev 2 has not made it
