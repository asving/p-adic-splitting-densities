## S2. LEG 2 — Lemma K2-L9 (the A = {0} safety lemma)

**Lemma K2-L9.**  On TRACK ∧ (H1)–(H3) ∧ g₀ = 2 ∧ c_{m−1} ≥ k, with

same-sign residue sum by cancellation.

*Proof, in five steps; the first four are the derived "singleton-safety
arithmetic", the fifth its consequence.*

**(1) One event per active window.**  Each available event consumes 2 units,
and a window fires while its running unit count is ≥ 2 (K2-L1(a)).  From an
opening budget n ∈ {2,3}: fire once (n ↦ n − 2 ∈ {0,1}), then n − 2 < 2, so
the window closes.  A budget n ≤ 1 fires nothing.  Hence every active window
holds EXACTLY ONE event — a C₀ or a promotion — and no window can hold two
events, because two events cost 4 units > 3 = 2g₀ − 1 (K2-L2).  Enumerated
inventory (machine-confirmed, S4):

    n ≤ 1:  []                              (nothing).
    n = 2:  [C₀] (units 2, p 0, f 0)  |  [promo] (units 2, p 1, f 0).
    n = 3:  [C₀] (units 2, p 0, f 1)  |  [promo] (units 2, p 1, f 1).

**(2) Singleton (units, p) classes — the in-window exchange is dead.**  In
the inventory above the two drains of any budget differ in p (0 vs 1), so
each (units, p) class holds exactly ONE drain.  The sole multi-member
(units, p) class anywhere at A = {0,1} is the in-window exchange
{C₁,C₁} ↔ {C₀} at n = 3, units 2, p 0 (K2-L3(ii)); it requires C₁, absent
here.  So under A = {0} there is no in-window sign-reversing pair.

**(3) Seed-disjoint slots — the cross-seed toggle is dead.**  Fix a group.
Total level-0 consumption = (#corrections + #promotions)·2 = EVEN.  The seed
arrival contributes t·e₀ to j₀, i.e. t units (W-D2(iv)†).  So for any cell of
seed t the parked unit count f_final = (arrival units) − (even) has the
parity of the t-independent base plus t.  Passing t ↦ t+1 adds one unit,
FLIPPING that parity.  Hence seed-t and seed-(t+1) cells park with opposite
unit-parity, i.e. at different j₀ — DISJOINT slots.  No bottom group mixes
seeds.  The cross-seed toggle (t, K) ↔ (t+1, K ∪ {C₁}) (K2-L3(iii)) would
rebalance the +1 seed unit with a mass-1 C₁; without C₁ the +1 cannot be
absorbed, so no cross-seed sign-reversing pair exists.

**(4) The A = {0} placement pair is budget-killed.**  The only remaining way
two cells of ONE group could differ is by moving a level-0 event between
windows at a fixed slot/book (the mechanism of box (e)).  A correction can
be moved between windows only while the per-window promotion profile (p_w)
is held fixed — otherwise the interior trajectory, which by K2-L1(b) depends
on the drain solely through (p_w), diverges and the two cells land in
different groups.  But holding the promo profile fixed pins each promotion to
its window; to also carry a C₀ in a promotion-bearing window that window
would need {C₀, promo} = 2 + 2 = 4 units > 3.  IMPOSSIBLE by K2-L2.  So a C₀
cannot be re-placed at a fixed promo profile: the C₀-placement is FORCED once
the promo profile is fixed.  The A = {0} analogue of the placement pair
therefore does not exist.  [Contrast box (e), S3: there the moved event is a
C₁ of mass 1, and {C₁, promo} = 1 + 2 = 3 ≤ 3 DOES fit — which is exactly why
(e) is budget-legal and A = {0} is not.]

**(5) Every group is single-sign; no involution move.**  A single-book group
fixes (I, π⃗, slot, line) and, by step (3), a single seed t.  Fixed π⃗ fixes
the promotion total p; fixed slot + seed + p fixes the correction count a
(parked = arrival(t) − 2a − 2p, all else fixed), and every correction is a
C₀ (A = {0}), so K = {C₀}^a is fixed.  By K2-L4 the sign (−1)^{a+|I|} and the
residue res(c_{D_t})·ψ̄₀^{a}·∏_{d∈I}res(c_d) depend only on (t, a, I) — all
fixed — so ALL cells of the group share one residue class and ONE sign.
Since P1/P2/T1 each contain a C₁ cell (K2-THM-A's forms), NONE of them can
occur under A = {0}; every group is an all-C₀, single-sign class.  There is
thus no opposite-sign pair inside any group, and steps (2)–(4) show no
cross-window/cross-seed pair either: the sign-reversing involution has NO
domain.  A group's netted sum Σ sgn·res = ±(#cells)·res (res ≠ 0), which
CANNOT be driven to zero by any sign cancellation — the (SURV-K2) failure
mode is absent on A = {0}.  ∎
