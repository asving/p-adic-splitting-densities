### S3.1 LEMMA WZ-1 (gr of the stage leaf field is a graded field)

> **LEMMA WZ-1.** For each m ∈ ℤ set
> gr(L)_m := {a ∈ L : dv(a) ≥ m}/{a : dv(a) > m} and gr(L) := ⊕_m gr(L)_m, with
> [a] := the class of a ∈ L^× in degree dv(a). Then:
> (a) gr(L) is a commutative graded ring, and [a][b] = [ab] ≠ 0 for all
>     a, b ∈ L^×;
> (b) every nonzero homogeneous element is invertible; in particular gr(L) has no
>     homogeneous zero divisors;
> (c) gr(L)_0 = k_L = ι(K), and **gr(L)_m is a 1-dimensional K-vector space for
>     every m ∈ ℤ** — "one K-line per dv-height".

*Proof.* (a) Well-definedness and distributivity are the ultrametric axioms;
[a][b] = [ab] is dv(ab) = dv(a) + dv(b), a valuation identity **on a field** —
there are no zero divisors to break it. (b) dv(a^{−1}) = −dv(a) and
[a][a^{−1}] = [1] ≠ 0 since 1 ∉ {dv > 0}. (c) gr(L)_0 = O_L/m_L = k_L; for
m ∈ ℤ pick any a with dv(a) = m (possible: dv(L^×) = ℤ), then for any b with
dv(b) ≥ m we have [b] = [b/a]·[a] with [b/a] ∈ gr(L)_0, so gr(L)_m = k_L·[a],
a K-line via ι. ∎

**Provenance.** This is **LEMMA GENTOW5-A0** (`GENTOW5_PROOF_2026-08-09.md`
L159–177, CERTIFIED 2026-08-12) run one level down, in exactly the frame GENHN's
own `[e2]` E3 erratum already re-aims at. GENTOW5's own point transposes

### S3.4 THEOREM WZ-A (the level-1 substitution theorem — all μ pins die)

> **THEOREM WZ-A.** Stage-α event as in S1, with κ > D′h and
> **R_N(T) = (T − s)^μ**, s ∈ K^×. Let w := −lift(s; κ) be the exact-height lift
> at height κ (LEMMA GENHN-LIFT / T1 (C6): integral on the live domain κ > D′h,
> dv(w(θ)) = κ, res(w(θ)/n(κ)(θ)) = −s), put Φ′₊ := Φ′ + w, and let B_k be the
> coefficients of the polynomial-ring expansion f = Σ_k B_k Φ′₊^k (no reduction).
> Then for every k < μ
>
>     **dv( B_k(θ) ) > (μ − k)·κ** ,
>
> i.e. the height-(μ−k)κ class of B_k(θ) vanishes: **all μ pins die at the graded
> level**, and the new side's multiplicative residual is T^μ.

*Proof.* Since Φ′ = Φ′₊ − w,

    f = Σ_j A_j (Φ′₊ − w)^j = Σ_k B_k Φ′₊^k,
    B_k = Σ_{j ≥ k} binom(j,k)·(−w)^{j−k}·A_j .

Evaluate at θ. This is a sum of products **in the field L**, so WZ-1 applies
term by term. By hypothesis on the lift, [−w(θ)] = ι(s)·N. By DEFINITION WZ-R,
[A_j(θ)] = ι(c_j)·N^{μ−j} when c_j ≠ 0 and dv(A_j(θ)) > (μ−j)κ when c_j = 0.
Hence every term of B_k(θ) has dv ≥ (j−k)κ + (μ−j)κ = (μ−k)κ, and the class of
B_k(θ) in gr(L)_{(μ−k)κ} is

    [B_k(θ)]_{(μ−k)κ} = Σ_j binom(j,k)·ι(s)^{j−k}·N^{j−k}·ι(c_j)·N^{μ−j}
                      = N^{μ−k} · ι( Σ_j binom(j,k) s^{j−k} c_j )
                      = N^{μ−k} · ι( [T^k] R_N(T + s) ),

the last step the Taylor/substitution identity: if R(T) = Σ_j c_j T^j then
R(T + s) = Σ_k ( Σ_j binom(j,k) s^{j−k} c_j ) T^k, an identity of polynomials
valid over any commutative ring, **both characteristics**. The factorization of
N^{μ−k} out of the sum is legitimate because gr(L) is commutative with N
invertible (WZ-1(b)). By hypothesis R_N(T) = (T − s)^μ, so
R_N(T + s) = (T + s − s)^μ = T^μ and [T^k]R_N(T+s) = 0 for every k < μ. A
vanishing class at height (μ−k)κ is exactly dv(B_k(θ)) > (μ−k)κ. At k = μ the
same display gives coefficient 1, so the new side's multiplicative residual is
T^μ. ∎

**Two honesty riders, both inherited verbatim from GENTOW5-A's proof.**
(i) The identity is a **substitution** identity — the binomials appear
transiently, but the conclusion (T − s)^μ|_{T↦T+s} = T^μ is binomial-free; where
char q divides binom(μ, k) the corresponding coefficients vanish on **both**
sides, so nothing is lost (battery frame F4 exercises char 3 at μ = 3, and F8/F11
exercise char 2). (ii) WZ-A is a statement about the **polynomial-ring**
coefficients B_k. Passing to the canonical Φ′₊-development coefficients A_k^new
(degree < D′) is **GENHN-4's own layer 2**, unchanged and not re-proved here
(WZ-BOX-1). Note that WZ-A is *stronger* than GENHN's layer 1 at the seam: layer
1 handles only the exact-height leading parts and hands "the products
w^{i−j}A_i" to layer 2, whereas WZ-A's conclusion is about the full B_k, so the
