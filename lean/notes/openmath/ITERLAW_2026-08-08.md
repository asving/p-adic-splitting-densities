## S2. The integer layer

**Lemma L1 (EQ12-ADD; CARRY-1's arithmetic half, GRB S5.2, restated at a general
level pair (e,h)).** For β, β′ ∈ ℤ with eq-(12-int) data (s,u), (s′,u′), (s″,u″) at
β, β′, β+β′ and δ := ⌊(s+s′)/e⌋: δ ∈ {0,1}, s″ = s+s′−δe, u″ = u+u′+δh.
*Proof.* 0 ≤ s+s′ ≤ 2e−2 gives δ ∈ {0,1} and s+s′−δe ∈ [0,e). Adding the defining
equations, (u+u′+δh)e + (s+s′−δe)h = β+β′; uniqueness of the eq-(12-int) pair at
β+β′ does the rest. ∎

**Lemma L2 (INNER-SHIFT).** For γ, γ′ ∈ ℤ, δ₂ := ⌊(s₂(γ)+s₂(γ′))/e₁⌋:
γ₁(γ+γ′) = γ₁(γ) + γ₁(γ′) + δ₂γ₂.
*Proof.* By L1 at level 2: s₂(γ+γ′) = s₂+s₂′−δ₂e₁, u₂(γ+γ′) = u₂+u₂′+δ₂h₁. Then
γ₁(γ+γ′) = u₂(γ+γ′) − s₂(γ+γ′)·w₁Φ₁ = (u₂+u₂′) + δ₂h₁ − (s₂+s₂′)w₁Φ₁ + δ₂e₁w₁Φ₁
= γ₁(γ) + γ₁(γ′) + δ₂(e₁w₁Φ₁ + h₁) = γ₁(γ) + γ₁(γ′) + δ₂γ₂. ∎
(The "outer wrap dumps γ₂ into the inner track" of the DITER display, as an
identity.)

**Lemma L3 (WINDOW).** γ, γ′ ∈ W ⟹ γ+γ′ ∈ W.
*Proof.* Write β := γ₁(γ), β′ := γ₁(γ′), β″ := γ₁(γ+γ′) = β+β′+δ₂γ₂ (L2). If
δ₂ = 0: by L1 at level 1, u(β″) = u(β)+u(β′)+δ₁h₀ ≥ 0. If δ₂ = 1:
e₀u(β″) = β″ − s(β″)h₀ = e₀(u(β)+u(β′)) + (s(β)+s(β′)−s(β″))h₀ + γ₂, and
s(β)+s(β′)−s(β″) ≥ −(e₀−1) while γ₂ = e₀e₁g₀h₀ + h₁ ≥ e₀h₀ + h₁, so
e₀u(β″) ≥ h₀ + h₁ > 0. ∎

## S3. The character layer

**Lemma L4 (EPS-CLOSED).** For every β ∈ ℤ: (s(β) − ℓ₀β)/e₀ ∈ ℤ and
ε₁(β) = z₁^{(s(β)−ℓ₀β)/e₀}.
*Proof.* From u(β)e₀ + s(β)h₀ = β: ℓ₀β = ℓ₀e₀u(β) + ℓ₀h₀s(β)
= ℓ₀e₀u(β) + (1−ℓ₀′e₀)s(β), so s(β) − ℓ₀β = e₀(ℓ₀′s(β) − ℓ₀u(β)) — integrality and
the exponent identity at once. ∎ (At e₀ = 1: ℓ₀ = 0, s ≡ 0, ε₁ ≡ 1.)

**Lemma L5 (EPS-MULT).** For β, β′ ∈ ℤ, δ₁ := ⌊(s(β)+s(β′))/e₀⌋:
ε₁(β)·ε₁(β′) = z₁^{δ₁}·ε₁(β+β′).
*Proof.* By L4 both sides are z₁-powers; exponents:
LHS: (s(β)+s(β′) − ℓ₀(β+β′))/e₀. RHS: δ₁ + (s(β+β′) − ℓ₀(β+β′))/e₀, and by L1
s(β+β′) = s(β)+s(β′) − δ₁e₀. Equal. ∎

**Lemma EXP (the compose kernel).** Let β, β′ ∈ ℤ, δ₂ ∈ {0,1}, β″ := β+β′+δ₂γ₂,
and δ₁ := ⌊(s(β)+s(β′))/e₀⌋. Then

    δ₁ + [ (s(β+β′) − ℓ₀(β+β′)) − (s(β″) − ℓ₀β″) ]/e₀
      = ( s(β) + s(β′) − s(β″) + ℓ₀γ₂δ₂ )/e₀ ,

an integer.
*Proof.* By L1, s(β+β′) = s(β)+s(β′)−δ₁e₀, and ℓ₀(β″−β−β′) = ℓ₀γ₂δ₂; substitute
both and collect over the common denominator e₀ — the δ₁ terms cancel.
Integrality: the left side is δ₁ plus a difference of two integers (L4 twice).
∎ (Two lines — the TR3-S2 Lemma-EXP genre on the nose.)
