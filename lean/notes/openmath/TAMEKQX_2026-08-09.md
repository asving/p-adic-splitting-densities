## S1. LEMMA TKQX-0 (unramified K is letter-blind)

**LEMMA TKQX-0.** Let K/F be UNRAMIFIED of degree f, and L = (e′, f′) any finite
extension of F (tame or wild, any letter). Then

      #Hom_F(L, K) = f′ · [f′ | f] · [e′ = 1] .

*Proof (one line).* Any subfield of an unramified extension is unramified, so
Hom = ∅ unless e′ = 1; and there is EXACTLY ONE unramified extension of each degree,
Galois cyclic, so L = F_{f′} embeds iff f′ | f, in exactly #Aut(L) = f′ ways. ∎
(Equivalently: TAMEK's TK-0 at K = (1, f, 0): e′ | 1 forces e′ = 1, then
g = gcd(1, q^f − 1) = 1 and the letter congruence is mod 1 — vacuous.)

**Conceptual reason:** unramified extensions are unique per degree; there is no twist
class to see. **Consequence:** for random monic f of degree n,

      X_K = Σ_{irreducible factors g of type (1, f′), f′ | f} f′

— a function of the SHAPE (the (e,f)-multiset of the factorization type) alone.
The letter layer (TK-0's congruence, TK-BOX-2's joint equidistribution) never enters:
every unramified-K moment at a menu-certified degree is decided by the committed
shape menus. This holds at EVERY residue characteristic (wild factors have e′ > 1
and contribute 0), so the symbolic-in-q comparison below is meaningful at all q.

## S4. SECTION TKQX-2 — the q-adic expansion protocol, and the live instance

### The protocol (precise statement)

Let A(q), B(q) be the two sides: B = the recursion side, an explicit rational
function with numerator/denominator degrees (a_B, b_B) READ OFF its symbolic
output; A = the truth side, E[X_K^k](n) as a function of the residue size q.
- **Degree bound on A (the honest step):** both sides are bounded as q → ∞
  (E[X_K^k] ≤ n^k uniformly), so the reduced form of A has num deg ≤ den deg.
  The denominator bound b_A is supplied by the structure theorem (the uniformity
  theorem's rational-form clause: A ∈ ℚ(q) with denominator dividing the
  recursion side's, up to the displayed cyclotomic factors). Where this step is
  consumed it is BOXED as an input (TKQX-BOX-2), not proved here.
- **Determination:** if A − B = P/(Q_A Q_B) with deg(Q_A Q_B) ≤ b_A + b_B, and the
  1/q-Laurent expansions of A and B agree through the coefficient of q^{−(b_A+b_B)}
  (i.e. b_A + b_B + 1 leading coefficients, both sides O(1)), then
  P = (A−B)·Q_A Q_B is a polynomial that is O(q^{−1}) at infinity, hence ZERO:
  **A = B exactly.**
- **The truth-side coefficients are codimension-graded configuration counts:**
  the falling moment E[(X_K)_r] is the expected number of ordered r-tuples of
  distinct K-roots; grading the Kac–Rice integral by collision codimension
  (valuations of root differences/conjugate differences), the coefficient of
  q^{−i} receives contributions from FINITELY many strata, each a q-uniform count.
  So each depth-D verification is a finite exact computation.
