## S2. PROOF

### S2.1 The stratum in classifier coordinates; lift-independence

If f̄ is separable, the level-0 factorization is distinct linear/irreducible
factors — order-0 decided shapes, disjoint from T(2,1,1). Otherwise
f̄ = (x − c̄)² for a UNIQUE c̄ ∈ F_q (char ≠ 2: c̄ = −ā₁/2, forced by
disc̄ = 0; char 2: c̄ = √ā₀, forced by ā₁ = 0 and perfectness of F_q).
Recenter: g = f(x + c) = x² + a₁′x + a₀′, c any lift of c̄, with

    a₁′ = a₁ + 2c,   a₀′ = c² + a₁c + a₀.

Two pinned digits come for free: ā₀′ = f̄(c̄) = 0 AND ā₁′ = f̄′(c̄) = 0 —
the second because c̄ is a DOUBLE root. (This is the interior-free fact
S2.5.) Lift-independence: replacing c by c + πd changes a₀′ by
a₁′πd + π²d² (v ≥ 2, since v(a₁′) ≥ 1) and a₁′ by 2πd (v ≥ 1) — so
v(a₀′) = 1, the letter res(a₀′/π), and membership are independent of the
lift. [machine: W10-RECENTER lift leg, c vs c + π on sampled members.]

Membership: the polygon of g on {(0, v(a₀′)), (1, v(a₁′)), (2, 0)} is one
side (0,1)–(2,0) iff v(a₀′) = 1 (the interior point has v(a₁′) ≥ 1 > 1/2
automatically). Slope 1/2 with denominator e = 2, length 2, so g = 1;
residual polynomial y − z̄, letter z̄ = res(a₀′/π) ≠ 0 exactly because
v(a₀′) = 1 exactly. Degree-1 residual is decided: no further read.

    stratum  ≅  F_q × F_q^* × q^(2N−3) free digit choices:
