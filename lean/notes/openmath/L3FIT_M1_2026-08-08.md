## S1. Method: exact structural exponent measurement (and its honest limits)

**Data.** For each tower, the full W1×W1 block of canonical level-3 anchor pairs
(W1 = [Γ₀, Γ₀+E₃), Γ₀ from `Composite3`'s deterministic window scan), measured
with the sealed calculus imported read-only: c₃(γ,γ′) =
val₃(φ_γφ_{γ′})/val₃(φ_{γ+γ′}) ∈ K₃.

**Exponent measurement.** In a finite field, exponents of a monomial value are
canonical only modulo the letter-relation lattice (M5's *AMB caveat). M1
therefore measures STRUCTURALLY, not by discrete log: the z̄-exponent is the top
SLOT INDEX of the single-nonzero-slot R₃-read (an exact integer); the z₂- and
z₁-exponents are read off the committed reads' build — z₂-exp = (definitional
ε₂-exponent ℓ₁′s−ℓ₁u at the slot weight) + (level-2 slot index of the digit's
R₂-read), z₁-exp = (definitional ε₁-exponent) + (inner R₁-slot index) +
(residue-unit dlog, flagged when ≠ 1); numerator and denominator measured the
same way and subtracted. EVERY structural triple is re-verified against the
exact field value (z̄^a z₂^b z₁^c == c₃ in K₃) before use; 1,231/1,244 pairs
measured structurally, the rest (multi-slot reads on deep-cascade rows) enter
verification only.

**The honest exclusion (found the hard way, run 1 of the driver).** On the
cascade strata the structural triple is a lattice-coset REPRESENTATIVE that can
differ from any universal integer formula's representative — the reduction step
hides letter content in residue units / ε₁-twisted digit representations:

* middle cascade (g₁ = 1 ∧ δ₂ = 1): e.g. T07 pair (94,94) measures (0,0,1)
  where the canonical constants give (0,1,5) — same field value (z₂ = −1 = z₁⁴
  there), different representative;
* inner cascade (g₀ = 1): the Case-II unit −ψ₀(0) = z₁ is dlog-ambiguous mod
  ord(z₁) (invisible at z₁ = 1, e.g. T08).

Rule: such rows are EXCLUDED from the exact solves (b-solve: 624 of 644
structural rows; c-solve: 512) and kept in the field-value verification, which
is representation-independent — the fitted law is verified on ALL 1,244 pairs
including every excluded row. Run 1 (no exclusion) found NO b/c fit up to
support 4 — the poisoning is real and the diagnosis (deviations exactly and
only on those strata, 32 rows, all field-equal) is in the driver's history;
run 2 = the committed artifact.

**Fitting.** Per slot: dedupe rows, projectively merge identical feature
columns (the merge report IS a findings list — S0.6), then enumerate supports
by size (1, 2, 3, …) over the merged classes and solve the exact overdetermined
ℤ-linear system by Fraction Gaussian elimination; a support wins iff it
reproduces EVERY solve row exactly. All minimal-size wins are reported (each
slot's winner was UNIQUE). Forced-feature analysis: a class is FORCED if no
support of size ≤ minimal+1 avoiding the whole class fits.
