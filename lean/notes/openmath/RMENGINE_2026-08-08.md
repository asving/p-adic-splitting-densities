## S2. The cell calculus (cells, the three identity families, the tree, exactness) — PROVED, generic

### S2.1 Cells, lines, initial decomposition

A **cell** is C = b·Φ₀^{j₀}Φ₁^{j₁}⋯Φ_{m−1}^{j_{m−1}} with b ∈ O[x],
b ≠ 0, deg b < d₀, j_l ∈ ℤ_{≥0}. Its **line** (level-m weight lower bound,
exact on reduced cells by L-LINE(iv)):

    line(C) := E_m·w₀(b) + Σ_{l<m} j_l·Γ_l.

C is **reduced** iff j_l ≤ P_l − 1 for every l; then deg C < deg Φ_m by the
degree telescope deg Φ_{l+1} = P_l·deg Φ_l ([ILN]† S4.1 (R1) + WELL-DEF(i),
via the S0.1 pin): deg C ≤ (d₀−1) + Σ_l(P_l−1)deg Φ_l = deg Φ_m − 1.

**Lemma L-CELL (cell decomposition; B-READ).** (i) Every 0 ≠ x ∈ O[x] with
deg x < deg Φ_m is a finite sum of DISTINCT reduced cells (iterated
Φ_{m−1}-, …, Φ₀-development; uniqueness of division), with w_m(x) =
min line over its cells. (ii) [B-READ] For any target β* ≤ w_m(x),

    R_{m,β*}(x) = Σ_{cells C of x, line(C) = β*, C on-grid} res(b̄_C)·𝔷(C; β*),

with 𝔷 and on-grid as defined in S3.1, and b̄_C := res(b_C/π^{w₀(b_C)}).
*Proof.* (i) is the iterated division algorithm plus the min-formula for
single digits (developments add; w₀ a valuation — the S0.2 base facts of
[IL]†, consumed as in [ILN]†). (ii) Induction on m: the level-m read of x
at β* reads the Φ_{m−1}-digit at each grid abscissa s_m(β*) + te_{m−1} with
coefficient ε_{m−1}(slot weight)·R_{m−1,slot weight}(digit)·(z_m-power t);
each digit is the sum of the cells with that j_{m−1}; digits strictly above
their slot line contribute 0 (READ-ADD-(m−1), [ILN]† S4.1); off-grid
j_{m−1} are not read. Unwinding to level 1 gives exactly the 𝔷-product of
S3.1 per cell. ∎

### S3.1 The formal read monomial 𝔷

Fix a target β* ∈ ℤ. For a cell C = b∏Φ_l^{j_l} define the **λ-chain** and

    t_l := (j_{l−1} − s_l(λ_l)) / e_{l−1},      λ_{l−1} := (λ_l − j_{l−1}γ_l) / e_{l−1},

where s_l(·) is the eq-(12-int) s-value at the read (e_{l−1}, h_{l−1}). C
is **on-grid at β*** iff t_l ∈ ℤ for every l (equivalently j_{l−1} ≡
s_l(λ_l) mod e_{l−1}; then λ_{l−1} ∈ ℤ automatically, since γ_l ≡ h_{l−1}
