## S1. Set-up and the two quantities

Random member: monic f of degree n over O (coefficients Haar-uniform), residue field
F_q. #roots(f) := the number of (1,1)-factors of the factorization type σ(f) — the
count of degree-1 unramified-split factors = #{roots of f in O}. Two expectations:

- **E_n(q)** := E[#roots], monic model (the charge's E_n).
- **E_n^proj(q)** := E[#roots in P¹] of the projectivized model (the density ρ(n,σ;q)
  of the corpus; normalization |Pⁿ(F_q)|). The committed BCFG rows are THIS model
  (their committed raw1 moment ≡ 1 — see S7).

Cluster yield: **ε_m(q)** := Σ_τ β_m(τ)·N(τ) — the expected number of (1,1)-factors
produced by a size-m cluster (all m roots reducing to one rational residue point), β_m
the corpus's monic single-cluster law. ε₁ = 1.

## S2. LEMMA A (level-0 telescope). For n ≥ 1,

    (I)   E_n = q·[ Σ_{k=1}^{n-1} (1 − 1/q) q^{−k} ε_k  +  q^{−n} ε_n ]

and projectively, with b_n := |Pⁿ(F_q)| = (q^{n+1}−1)/(q−1),

    (I')  E_n^proj = (q+1)·[ Σ_{k=1}^{n} ε_k q^{n−k} ] / b_n .

**Proof.** The level-0 reduction of the random member is uniform on the qⁿ monic
degree-n polys over F_q (resp. the b_n degree-n effective divisors on P¹). #roots is
ADDITIVE over the level-0 Hensel product, and a closed point of residue degree δ ≥ 2
contributes 0 (every factor over it carries f ≡ 0 mod δ, so no (1,1)); a rational point
of multiplicity k contributes ε_k, independent of the rest (Hensel/cell independence at
order 0). For a FIXED rational point x: #{monic deg-n f̄ with mult_x(f̄) = k exactly} =
q^{n−k} − q^{n−k−1} (k < n; divide by (X−x)^k, demand g(x) ≠ 0) and 1 at k = n; so
P(mult_x = k) = (1−1/q)q^{−k} (k<n), q^{−n} (k=n). Sum over the q rational points of
A¹ (resp. q+1 of P¹, where #{divisors, mult_x = k exactly} = b_{n−k} − b_{n−k−1} =
q^{n−k}). ∎  (Order-0 material only: the level-0 product and uniform reduction — the
same supplier stack as W-11's level-0 partition; **HE-free**.)

## S3. LEMMA B (deep/shallow cluster split). For m ≥ 2,

    (II)  ε_m = Σ_{j=0}^{m} P_m(j) · E_j ,     E_0 := 0, E_1 = 1,

where P_m(j) := P(exactly j of the m cluster roots have valuation ≥ 1).

**Proof.** Recenter the cluster at 0: f = x^m + a_{m−1}x^{m−1} + … + a_0 with
v(a_i) ≥ 1 all i, coefficients conditionally Haar. Split the roots by the Newton
polygon at height-slope 1: the **deep** part (valuation ≥ 1, say j roots) and the
**shallow band** (valuation in (0,1), m−j roots).

1. *The shallow band is root-free:* a rational root has integer valuation; (0,1)
   contains none. So the ENTIRE internal structure of the shallow band — every
   fractional face, every composite stage inside it, in particular every μ≥3
   composite-over-fractional stratum — drops out of the (1,1)-marginal. Only the
   SPLIT PROBABILITY P_m(j) survives.
2. *The deep factor re-enters the full monic law:* f = h·u along the slope-1 polygon
   split (Hensel along coprime slope supports), h monic of degree j with all roots of
   valuation ≥ 1, i.e. h(x) = x^j + c_{j−1}x^{j−1} + … with v(c_i) ≥ j−i; rescaling
   h(πy)/π^j is monic with integral coefficients and — conditionally on the cell —
   uniform (the α-species self-similar re-entry: the same integer-slope cell law that
   gives the corpus's self-loop branch β_m = q^{−m(m−1)/2}·FULLMONIC(m) + SHALLOW_m;
   j = m IS that self-loop, P_m(m) = q^{−m(m−1)/2}). Its expected (1,1)-count is E_j.
3. Additivity of expectation over the split gives (II). ∎

**Supplier honesty:** step 2's conditional-uniformity is the W-12.D-type integer-slope
cell law (the α-bracket / re-based re-entry of the composed chain) — order-0/1
material, consumed at every j. **No μ≥3 composite-stage law is consumed anywhere in
(I)+(II)**: the only place μ≥3 strata live is inside the shallow band, which
contributes only its probability mass. Hence (S6) the expectation is 100% HE-free.

(check C5) — an independent confirmation of the cell-law instance at every realized

## S4. LEMMA C (the deep-count law and the KEY identity)

Write u_i := v(a_i) − 1 ≥ 0 (i < m), iid with P(u ≥ s) = q^{−s} under the cluster
conditioning. Set t_i := i + v(a_i) = i + u_i + 1 (i < m), t_m := m. Then (standard
support-line reading of the Newton polygon) **j = max argmin_i t_i**, and:

    P_m(m) = q^{−m(m−1)/2};   for 0 ≤ j < m:
    P_m(j) = Σ_{μ=j+1}^{m−1} P(u_j = μ−j−1) · Π_{k<j} P(u_k ≥ μ−k−1) · Π_{j<k<m} P(u_k ≥ μ−k)

(ties allowed left of the argmax, strict right of it). In particular

    P_m(0) = (1−1/q) Σ_{μ=1}^{m−1} q^{ 1−μ−μ(μ−1)/2 } ,
    P_m(1) = (1−1/q) Σ_{μ=2}^{m−1} q^{ 3−2μ−(μ−1)(μ−2)/2 } .

**KEY IDENTITY.**  q·P_m(0) − P_m(1) = q − 1   for every m ≥ 2.

**Proof.** Exponent bookkeeping: the μ-term of q·P_m(0) has q-exponent
2−μ−μ(μ−1)/2 = 2−μ(μ+1)/2, and the μ-term of P_m(1) has exponent
3−2μ−(μ−1)(μ−2)/2 = 2−μ(μ+1)/2 — **identical**. So the sums cancel PAIRWISE for
μ = 2..m−1, leaving only the μ=1 term of q·P_m(0): (1−1/q)·q^{2−1−0} = q−1. ∎

(Also: Σ_j P_m(j) = 1 — it is a partition; j = m−1 is impossible — a lone shallow root
would need integer valuation in (0,1). Both machine-checked, C4.)

## S5. THEOREM (the closed form, all n at once)

**E_n(q) = q/(q+1) for every n ≥ 2** (and E_1 = 1); equivalently through (I):
**ε_m(q) = 1/(q+1) for every m ≥ 2** (ε₁ = 1). Moreover **E_n^proj(q) = 1 for every
n ≥ 1** — the projective model has expected root count EXACTLY one, at every degree
and every q; each of the q+1 rational points of P¹ carries expected root mass
1/(q+1), and the monic value is the affine window: E_n = 1 − 1/(q+1) = q/(q+1).

**Proof** (strong induction on m; both statements (E_m, ε_m) simultaneously).

*Base m=2:* (II) is ε₂ = P₂(2)E₂ = q^{−1}E₂ (P₂(0) = 1−1/q kills E₀, P₂(1) = 0);
(I) is E₂ = (1−1/q) + q^{−1}ε₂. Solving: E₂ = (1−1/q)/(1−q^{−2}) = q/(q+1) — which is
W-11's accepted value, re-derived — and ε₂ = 1/(q+1).

*Step m ≥ 3:* assume E_j = q/(q+1), ε_j = 1/(q+1) for 2 ≤ j ≤ m−1. Then (I) and (II)
are two affine equations in the two unknowns (E_m, ε_m):

- (I): E_m = (1−1/q) + (q^{−1} − q^{1−m})/(q+1) + q^{1−m}·ε_m
  [the geometric sum (q−1)Σ_{k=2}^{m−1}q^{−k} = q^{−1} − q^{1−m}],
- (II): ε_m = P_m(1)·1 + (Σ_{j=2}^{m−1}P_m(j))·q/(q+1) + q^{−m(m−1)/2}·E_m.

The system is nondegenerate: the composed self-map coefficient is
q^{1−m}·q^{−m(m−1)/2} < 1 (a contraction — unique solution). Verify that
(E_m, ε_m) = (q/(q+1), 1/(q+1)) solves it: for (I), (1−1/q) + q^{−1}/(q+1) =
(q²−1+1)/(q(q+1)) = q/(q+1) ✓ (the q^{1−m} terms cancel exactly). For (II), write
E_j = q/(q+1) + [j=1]·1/(q+1) − [j=0]·q/(q+1); then using Σ_j P_m(j) = 1,

    Σ_j P_m(j)E_j = q/(q+1) − ( q·P_m(0) − P_m(1) )/(q+1) = q/(q+1) − (q−1)/(q+1) = 1/(q+1)

by the **KEY IDENTITY** — noting the j=m term enters through the first summand with
E_m = q/(q+1) (the fixed point re-enters itself). ∎

**The one-line recursion** (the answer to the charge's (1)): substituting (II) into
(I), E_n obeys the self-consistent telescope

    E_n = (1−1/q) Σ_{k=1}^{n−1} q^{1−k} [ Σ_{j≤k} P_k(j) E_j ]  +  q^{1−n} Σ_{j≤n} P_n(j) E_j ,

whose unique bounded solution is the constant q/(q+1) (n ≥ 2). The α-species enters
as the self-loop j=m (coefficient q^{−m(m−1)/2}, the fixed-point re-entry); the
β-species as the lower-degree re-entries E_j, j < m; the composite stages contribute
NOTHING to the (1,1)-marginal beyond their mass (S3.1).
